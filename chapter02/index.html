    💡 왜 이걸 배우나요?¶

    아침에 눈을 떠서 저녁에 잠들기까지, 당신은 얼마나 많은 데이터를 남기고 있을까요?

    스마트폰으로 메시지를 보내고 📱, 유튜브 영상을 재생하고 🎬, 걸음 수가 기록되고 👣, 검색 기록이 저장돼요. 이 모든 것이 바로 데이터입니다.

    "데이터 시대"라는 말을 자주 들어봤을 거예요. 대기업들은 왜 데이터를 금처럼 소중히 여길까요? 데이터를 분석하면 미래를 예측할 수 있고, 더 나은 결정을 내릴 수 있기 때문입니다. 유튜브가 당신이 좋아할 만한 영상을 추천하고, 배달앱이 당신 근처 맛집을 알려주는 것도 모두 데이터 분석의 덕분이에요.

    이 장에서는 데이터의 기본개념을 배워요. 어렵지 않아요. 우리가 이미 사용하고 있는 것들을 다시 바라보는 관점을 갖는 것일 뿐이니까요! 🌟

    📚 핵심 개념¶

    개념 1: 데이터와 정보 — 날것과 요리된 음식¶

    🥘 비유로 시작해요

    데이터와 정보의 관계를 음식으로 생각해 볼게요.

    • 데이터 = 마트에서 사온 채소, 고기, 쌀 (날것 그대로)
    • 정보 = 어머니가 만든 맛있는 된장찌개 (가공되고 의미가 담긴 음식)

    데이터는 그냥 수집된 숫자나 글자일 뿐이지만, 이것을 분석하고 정리하면 의미 있는 정보가 돼요.

    📖 정확한 정의

    데이터(Data): 현실을 기술한 가공되지 않은 기초 자료 정보(Information): 데이터를 처리·분석하여 의미를 부여한 결과

    이 정의는 2022 개정 교육과정에서도 사용하는 표현이에요.

    💭 예시로 확인해요

    시나리오: 서울의 날씨를 알고 싶다고 해볼게요.

    📊 데이터 → 정보로 변환되는 과정:

[데이터] (날것 그대로)
- 서울, 09:00, 기온 15°C, 습도 65%, 흐림
- 서울, 10:00, 기온 16°C, 습도 62%, 맑음
- 서울, 11:00, 기온 18°C, 습도 58%, 맑음

  ↓ (분석 과정)

[정보] (의미 있는 결과)
→ "오늘 오전 9시부터 11시까지 서울의 기온이 
   점차 올라가며 날씨가 맑아질 거 같아요"

    데이터는 숫자들의 나열이지만, 이를 비교·분석하면 미래를 예측할 수 있는 정보로 변신해요!

    개념 2: 정형 데이터 vs 비정형 데이터¶

    🎯 무엇이 다를까?

    데이터는 생김새에 따라 두 가지로 나뉘어요.

    📊 정형 데이터(Structured Data)

    "깔끔하게 정렬된" 데이터를 말해요. 엑셀 스프레드시트처럼 행과 열로 정렬되어 있어서 컴퓨터가 이해하기 쉬워요.

    학생 이름 | 수학 점수 | 영어 점수 | 음악 점수
─────────┼──────────┼──────────┼──────────
김철수   |    85   |    92   |    78
이영희   |    91   |    87   |    85
박민준   |    78   |    88   |    92

    정형 데이터의 특징: - 💾 스프레드시트, 데이터베이스에 잘 맞음 - 🔍 분석하기 쉬움 (평균, 최댓값 계산 간단) - 📈 그래프나 통계 작성이 간단

    📝 비정형 데이터(Unstructured Data)

    "자유로운 형태의" 데이터예요. 정해진 틀이 없어서 형태가 다양해요.

    비정형 데이터의 예시: - 📸 사진과 영상 - 🔊 음성 파일 - ✍️ 일기나 블로그 글 (텍스트) - 📰 뉴스 기사 - 💬 SNS 댓글

    비정형 데이터의 특징: - 🎨 형식이 자유로움 - 🧠 컴퓨터가 이해하기 어려움 - ⏱️ 분석에 시간이 오래 걸림

    💡 함께 생각해 보기

    당신이 인스타그램에 올린 사진과 설명글을 생각해 봐요.

    • 📸 사진: 비정형 데이터 (픽셀의 집합, 형태가 정해지지 않음)
    • ✍️ 텍스트: 비정형 데이터지만, 좋아요 개수, 댓글 수는 정형 데이터!

    개념 3: 일상 속 데이터 수집¶

    👀 당신은 얼마나 많은 데이터를 남기고 있을까?

    아침 7시부터 저녁 11시까지 당신의 하루를 따라가 봐요.

    시간      | 활동                    | 생성되는 데이터
──────────┼────────────────────────┼──────────────────────
07:00     | 알람으로 깨어남         | 깬 시간, 깬 위치
08:30     | 카카오톡으로 친구와 대화 | 메시지 내용, 발신 시간
09:15     | 유튜브에서 영상 시청     | 검색 키워드, 시청 영상,
         |                        | 시청 길이, IP 주소
14:00     | 지도앱으로 병원 검색     | 검색 위치, 검색 장소
18:30     | 배달앱에서 음식 주문     | 주문 음식, 위치, 결제
         |                        | 시간, 카드 정보

    잠깐, 이게 다가 아니에요! 🤯

    • 📱 스마트폰 배터리 사용량
    • 🖱️ 키보드 입력 속도
    • 👁️ 화면 밝기 조절 패턴
    • 📍 GPS 위치 기록

    이 모든 것들이 데이터로 저장되고 있어요!

    🤔 이게 왜 중요할까?

    이런 데이터들을 모아서 분석하면: - 유튜브가 "당신이 좋아할 만한 영상" 추천 📹 - 배달앱이 "자주 시키는 음식점" 알려줌 🍕 - 음악 앱이 "당신의 취향 플레이리스트" 만들어줌 🎵

    개인화된 서비스는 모두 당신의 데이터로부터 시작돼요!

    개념 4: 데이터의 3가지 분류¶

    지금까지 배운 것을 정리하면, 데이터를 3가지 각도로 분류할 수 있어요.

    분류 1: 형태에 따라

    graph TD A["📊 데이터"] --> B["정형 데이터<br/>(Structured)"] A --> C["비정형 데이터<br/>(Unstructured)"] B --> B1["예: 성적표, 판매액<br/>특징: 행과 열로 정렬"] C --> C1["예: 사진, 영상, 글<br/>특징: 형태가 자유로움"]

    분류 2: 출처에 따라

    • 생성형 데이터: 당신이 자발적으로 만드는 것 (게시물, 댓글, 사진 업로드)
    • 자동 생성 데이터: 활동하면서 자동으로 저장되는 것 (검색 기록, GPS, 클릭 기록)

    분류 3: 시간에 따라

    • 정적 데이터: 변하지 않는 정보 (주민등록번호, 생년월일)
    • 동적 데이터: 계속 변하는 정보 (실시간 날씨, 주식 가격, 유튜브 조회수)

    💡 잠깐! 여기까지 개념이 잘 이해되었나요? 어려워 보일 수 있지만, 사실 우리가 이미 매일 접하는 것들이에요. 다음 섹션에서는 직접 찾아보면서 더 명확히 이해하게 될 거예요! 😊

    🔨 따라하기: 내 주변의 데이터 찾기¶

    이제 이론만으로 끝내지 말고, 실제로 여러분의 삶 속에서 데이터를 찾아봐요!

    단계 1: 당신의 스마트폰 들어보기¶

    지난 24시간 동안 어떤 앱을 사용했는지 확인해 봐요. (iPhone: 설정 → 스크린타임 / Android: 설정 → 디바이스 관리 → 배터리)

    발견되는 데이터들: - 📱 앱 사용 시간 (정형 데이터 - 숫자) - 🔄 앱 사용 빈도 (정형 데이터 - 순서) - 📸 스크린샷 (비정형 데이터)

    단계 2: 지난 1주일 검색 기록 정리하기¶

    구글 검색창에 "당신의 활동"을 검색해 보세요. (또는 모바일앱 → 설정 → 검색 기록)

    예시: - 검색어: "맛있는 카페", "영화표 예매", "수학 문제 풀이" - 이것이 데이터: 시간, 검색어, 위치 정보

    분류해 보기: - 정형 데이터? 비정형 데이터? 생각해 보세요!

    ✅ 체크포인트: 지난 일주일 검색 기록 중에서 최소 3개를 찾았다면 성공! 각각을 "정형인지 비정형인지" 구분할 수 있나요?

    단계 3: 당신의 SNS 분석하기¶

    인스타그램, 페이스북, 틱톡 중 하나를 선택해서 지난 3개월 활동을 정리해 봐요.

    정리해 볼 데이터:

    항목              | 당신의 데이터      | 종류
────────────────┼──────────────┼──────────────────
업로드한 게시물 수 | ___개         | 정형 (숫자)
평균 좋아요 수   | ___개         | 정형 (숫자)
가장 많은 좋아요  | ___개         | 정형 (숫자)
업로드한 이미지  | ___개         | 비정형 (사진)
작성한 댓글 수   | ___개         | 정형 (숫자)

    단계 4: 학교 성적표로 데이터 이해하기¶

    학교 성적표를 떠올려 봐요. (또는 다운로드 받아 봐요)

    성적표는 대표적인 정형 데이터입니다: - 학생이름 | 국어 | 수학 | 영어 | 과학 | ... - 각각의 칸이 정해져 있음 ✅ - 숫자로 표현됨 ✅ - 비교·분석이 쉬움 ✅

    발견할 수 있는 정보들: - 전체 평균은? (데이터를 계산해서 정보로!) - 가장 잘한 과목은? - 가장 어려운 과목은?

    단계 5: 비정형 데이터 찾기¶

    이번엔 정형 데이터만 있는 게 아니에요. 비정형 데이터도 찾아봐요!

    당신의 카카오톡 채팅방을 예로 들어볼게요:

    • ✍️ 텍스트 메시지: 비정형 데이터 (글의 형태가 자유로움)
    • 🖼️ 이모지, 이미지: 비정형 데이터
    • ⏰ 메시지 발송 시간: 정형 데이터! (시간은 숫자)
    • 📞 통화 시간: 정형 데이터 (초 단위 숫자)

    ✅ 체크포인트: 카카오톡 채팅방에서 정형과 비정형 데이터를 각각 3개씩 찾았다면 완벽해요!

    단계 6: 하루를 "데이터로 기록"해 보기¶

    내일 하루를 의식적으로 관찰해 보세요. 어떤 데이터가 생성되는지요!

    기록 양식: 

    시간      | 활동          | 생성되는 데이터 | 정형/비정형
──────────┼──────────────┼────────────────┼──────────
08:00     | 아침 밥 먹음   | 먹은 시간, 위치 | 정형
08:30     | 인스타그램 보기 | 본 영상, 시간  | 혼합
09:00     | 공부하기      | 공부 시간       | 정형

    처음에는 어려울 수 있지만, 이 습관을 들이면 데이터적 사고가 자연스러워져요!

    ⚠️ 자주 하는 실수¶

    실수 1: "데이터 = 숫자"라고 생각하기¶

    ❌ 잘못된 생각: "데이터는 숫자만 있는 거 아닌가?"

    왜 이런 일이 생기나요? 학교에서 처음 배우는 데이터가 성적표나 통계(숫자)라서 그래요. 하지만 사진, 영상, 텍스트도 모두 데이터예요!

    ✅ 이렇게 해결해요: 데이터 = 의미를 담은 모든 정보 (숫자, 글, 이미지, 영상 등)

    실수 2: 정보와 데이터를 구분 못 하기¶

    ❌ 잘못된 생각: "데이터와 정보는 같은 거 아닌가?"

    예시로 확인해요: - 📊 데이터: "85점, 92점, 78점" (날것의 숫자들) - 📈 정보: "평균 85점이니까 전체적으로 잘했네요" (의미 있는 결과)

    ✅ 이렇게 해결해요: - 데이터 = 수집된 원본 그대로 - 정보 = 분석·해석된 의미 있는 결과

    실수 3: 비정형 데이터를 "정보"로 착각하기¶

    ❌ 잘못된 생각: "텍스트로 쓰인 건 이미 정보지, 데이터가 아니야"

    예시: - "영화 꿈의궁전은 정말 재미있어요!" (블로그 글) - 이건 정보처럼 보이지만, 아직 분석되지 않은 원본 데이터예요!

    ✅ 이렇게 해결해요: - 이 글을 분석해야 정보가 됨 - 예: 영화 평점 분석, 감정 분석 (긍정/부정) 등

    📝 전체 정리: 이 장의 핵심 정보¶

    🎯 한눈에 보는 핵심 개념

    ① 데이터란? - 현실을 기술한 가공되지 않은 기초 자료 - 정보로 변환될 수 있는 원본 재료

    ② 데이터 vs 정보 - 데이터: 채소, 고기 같은 날것 - 정보: 요리사가 만든 요리

    ③ 정형 데이터 - 행과 열로 정렬 (엑셀처럼) - 예: 성적표, 판매액 기록 - 분석이 쉬움 ✅

    ④ 비정형 데이터 - 형태가 정해지지 않음 - 예: 사진, 영상, 글, 댓글 - 분석이 어려움 (AI 기술 필요)

    ⑤ 당신의 데이터 - 스마트폰에 저장되는 모든 활동 - 자동으로 수집되고 기업에서 활용됨 - 개인화 서비스의 원천
