    Chapter 01. 왜 데이터과학을 배워야 할까? — 이 책의 사용법¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다: - [ ] 일상에서 만나는 3가지 이상의 데이터과학 사례를 설명할 수 있어요 - [ ] 이 책의 전체 학습 로드맵을 이해하고 자신만의 학습 계획을 세울 수 있어요 - [ ] 인문·언어 역량이 데이터과학에서 왜 강점인지 자신감 있게 말할 수 있어요

    예상 학습 시간: 약 60분

    📚 미리 알아야 할 것¶

    이 책은 완전 입문자를 위해 쓰였어요. 수학을 잘하거나 프로그래밍 경험이 있을 필요가 없습니다. 오히려 책을 읽고, 글을 쓰고, 생각을 정리하는 것을 좋아한다면 데이터과학을 배우기에 최고의 준비가 되어 있는 거예요! 🌟

    📖 Part 1. 들어가며¶

    데이터는 세상을 읽는 또 하나의 언어¶

    넷플릭스를 켜면 당신이 본 영화들을 바탕으로 다음에 볼 만한 작품을 추천해줘요. 유튜브의 추천 영상도, 인스타그램의 피드도, 스포티파이의 플레이리스트도 모두 그래요.

    이건 마법이 아니에요. 수많은 데이터(당신이 본 영상의 장르, 재생 시간, 평점)를 모아서 패턴을 찾은 거랍니다. "아, 이 사람은 코미디를 자주 본다", "이 사람들은 공통으로 이 영화를 좋아한다" 같은 규칙을 찾아내는 거죠.

    데이터과학은 마치 외국어를 배우는 것처럼 생각할 수 있어요.

    🌍 당신이 매일 마주치는 데이터과학 3가지¶

    1️⃣ 추천 시스템 (당신의 취향을 읽다)¶

    • 넷플릭스: "이 영화 본 사람들이 이것도 봤어요"
    • 아마존: "당신이 본 책과 비슷한 상품"
    • 스포티파이: "당신을 위한 플레이리스트"

    당신의 행동(클릭, 재생, 평점)이 모두 기록되고, 그것들이 패턴을 만들어요.

    2️⃣ 소셜미디어의 알고리즘 (당신의 관심을 예측하다)¶

    인스타그램을 5분만 켜도 시간이 훅 가버린 경험 있나요? 그건 알고리즘이 "이 사람은 여행 사진을 오래 본다", "운동 관련 콘텐츠에 댓글을 자주 남긴다"는 패턴을 학습했기 때문이에요.

    3️⃣ 여론조사와 선거 분석 (흐름을 읽다)¶

    "지지도 45%, 신뢰도 95%" 같은 여론조사도 데이터과학이에요. 1,000명을 조사해서 전체 국민의 마음을 예측하는 거죠. 마치 국에서 한 숟가락 떠서 맛을 보면 전체 국의 맛을 알 수 있는 것처럼요.

    💡 잠깐! 당신도 지금 이 순간 데이터를 생산하고 있어요. 이 책을 읽는 시간, 클릭하는 페이지, 머물렀던 시간까지 모두 데이터가 되고 있답니다. 그런데 이제 당신은 받는 쪽에서 만드는 쪽으로 전환할 거예요! 🚀

    🗣️ 언어 잘하는 사람이 데이터에도 강한 이유¶

    여기서 흥미로운 발견이 있어요.

    외국어 배우기 ↔ 데이터 읽기는 정말 비슷합니다:

    영어를 배울 때 단어(vocabulary)→ 문법(grammar) → 문맥(context)을 배우죠. 데이터도 똑같아요: - 단어 = 데이터 타입 (숫자, 텍스트, 날짜...) - 문법 = 데이터를 다루는 규칙 (계산, 정렬, 필터링...) - 문맥 = 데이터가 의미하는 바 ("이 수치가 왜 중요할까?")

    책을 많이 읽는 사람, 글쓰기를 좋아하는 사람, 토론을 잘하는 사람은 이미 패턴 인식 능력이 뛰어나요. "이 글의 주제가 뭘까?", "이 문장이 왜 여기 들어갔을까?", "이 사람이 정말 말하고 싶은 게 뭘까?"를 계속 물어오셨거든요.

    데이터도 똑같은 질문을 던져요: - "이 데이터가 말해주는 패턴이 뭘까?" - "이 숫자들이 왜 이렇게 움직였을까?" - "데이터가 정말 보여주는 진실이 뭘까?"

    인문학적 사고력이 데이터 해석의 진짜 핵심입니다. 프로그래밍은 도구일 뿐이에요. ✨

    📍 이 책의 학습 로드맵¶

    이 책은 총 4개의 Part로 구성되어 있고, 21차시(총 21시간)로 설계되었어요. 마치 외국어를 배울 때처럼 단계적으로 올라갑니다:

    graph LR A["Part 1<br/>데이터의 언어<br/>1-4차시"] --> B["Part 2<br/>데이터 만나기<br/>5-12차시"] B --> C["Part 3<br/>데이터 해석하기<br/>13-18차시"] C --> D["Part 4<br/>데이터 이야기하기<br/>19-21차시"] style A fill:#FFE5E5 style B fill:#E5F3FF style C fill:#E5FFEB style D fill:#FFF5E5

    각 Part의 목표¶

    🎓 Part 1: 데이터라는 새로운 언어와 만나기 (1-4차시) - 데이터가 뭔지, 왜 배워야 하는지 이해하기 - 도구 (오렌지3, 파이썬) 설치하고 친해지기 - 첫 번째 데이터 분석 경험하기

    📊 Part 2: 데이터를 수집하고 정리하기 (5-12차시) - 엑셀, CSV 파일 다루기 - 데이터 정제 (오류 제거, 중복 처리) - 데이터를 시각화해서 패턴 찾기

    🔍 Part 3: 데이터의 의미를 파악하기 (13-18차시) - 통계의 기초 개념 이해하기 - 머신러닝으로 예측하기 - 상관관계와 인과관계 구분하기

    🎤 Part 4: 데이터로 이야기 만들기 (19-21차시) - 데이터 시각화를 통해 설득력 있게 전달하기 - 대시보드 만들기 - 최종 프로젝트 완성하기

    📌 중요해요! 각 Part는 독립적이지 않아요. Part 1을 건너뛸 수는 없답니다. 마치 외국어를 배울 때 단어를 모르면 문법을 배워도 소용없는 것처럼요!

    🛠️ 이 책에서 사용할 두 가지 도구¶

    도구 1️⃣: 오렌지3 (Orange3) — 시각적 프로그래밍¶

    뭔가요? 오렌지3는 "블록을 연결하듯이" 데이터 분석을 하는 프로그램이에요. 코딩을 전혀 안 해도 돼요. 마우스로 블록을 끌어다 연결하면 돼요.

    왜 먼저 배워요? - 직관적이라 데이터 분석의 큰 흐름을 빠르게 이해할 수 있어요 - "코딩이 두렵다"는 심리적 부담을 덜어줘요 - 결과를 시각적으로 즉시 볼 수 있어요

    예: "이 데이터를 읽어서 → 필터링해서 → 그래프로 보여줘" 이 세 단계를 블록 3개로 쉽게 할 수 있어요.

    도구 2️⃣: 파이썬 (Python) — 진짜 프로그래밍¶

    뭔가요? 파이썬은 세계에서 가장 많이 쓰이는 프로그래밍 언어예요. 데이터과학자들의 "공용어"라고 생각하면 돼요.

    왜 배워야 해요? - 오렌지3로는 할 수 없는 복잡한 분석이 가능해요 - 실무에서 정말로 사용하는 기술이에요 - 한 번 배워두면 평생 써요

    안심해요! 파이썬은 영어처럼 읽힐 정도로 쉬워요. 이 책을 따라가다 보면 자연스럽게 배워지는 구조로 설계했답니다.

    📋 이 책의 사용 방법¶

    1단계: 환경 준비 (Part 1, 2차시)¶

    오렌지3와 파이썬을 설치해요. 걱정하지 마세요, 자세한 가이드가 있어요.

    2단계: 이해하기¶

    각 장을 읽으면서 핵심 개념을 이해해요. 비유와 예시가 많으니 어렵지 않을 거예요.

    3단계: 실습하기¶

    "따라하기" 섹션에서 코드나 오렌지3 블록을 직접 실행해봐요. 반드시 손을 움직여야 해요! 읽기만 해서는 데이터과학을 배울 수 없어요. 마치 외국어를 배울 때 직접 말해봐야 하는 것처럼요.

    4단계: 점검하기¶

    각 장 끝의 "점검하기"로 이해도를 확인해요.

    5단계: 프로젝트하기¶

    Part 마다 작은 프로젝트가 있어요. 배운 것들을 종합해서 실제로 무언가를 만들어봐요.

    ✨ 격려의 말씀: 처음에는 어려울 수 있어요. 하지만 각 장은 단 1시간 분량으로 설계되어 있어요. 충분히 따라올 수 있습니다! 중요한 건 "완벽하게" 이해하는 게 아니라 "계속 진행하는 것"이에요. 어려운 부분이 있으면 그냥 넘어가고 다음 장에서 다시 나올 때 이해해도 괜찮아요.

    📌 이 장의 핵심 정리¶

    ✅ 데이터과학은 일상 모든 곳에 있어요 - 추천 시스템, SNS 알고리즘, 여론조사 모두 데이터과학이에요 - 당신도 지금 데이터를 만들고 있어요

    ✅ 데이터는 언어처럼 배워요 - 단어(데이터 타입) → 문법(처리 규칙) → 문맥(의미 파악) - 인문학적 사고가 진짜 강점이에요

    ✅ 체계적인 로드맵이 있어요 - Part 1(개념) → Part 2(수집/정리) → Part 3(해석) → Part 4(전달) - 총 21시간, 일주일이면 완성 가능해요

    ✅ 두 가지 도구를 쓸 거예요 - 오렌지3: 시작하기 쉬워요 - 파이썬: 강력해요

    🤔 스스로 점검해 봐요¶

    다음 질문에 답할 수 있나요?

    1. 넷플릭스 추천이 정확한 이유를 데이터과학으로 설명해 보세요.

      정답 확인 당신의 시청 기록(클릭, 재생 시간, 평점 등)이 데이터로 기록되고, 비슷한 시청 패턴을 가진 다른 사람들이 본 영상을 찾아서 추천하기 때문이에요. 이건 "당신이 이걸 봤으면 이것도 좋아할 가능성이 높다"는 패턴을 데이터에서 발견한 거예요.

    2. 인문학적 역량이 데이터과학에 왜 도움이 될까요?

      정답 확인 책을 많이 읽고 글을 잘 다루는 사람은 "패턴 인식"과 "맥락 이해"에 이미 뛰어나기 때문이에요. 데이터 분석도 결국 "이 수치들이 말해주는 패턴이 뭘까?"와 "왜 이렇게 되었을까?"라는 같은 질문이거든요.

    3. Part 1에서 배울 주요 내용 3가지를 말해보세요.

      정답 확인 ① 데이터과학이 뭔지, 왜 배우는지 이해하기 ② 오렌지3와 파이썬 도구 설치하고 친해지기 ③ 첫 번째 데이터 분석으로 성취감 느껴보기
