    Chapter 04. 데이터의 종류와 형태 이해하기¶

    🎯 이 장의 학습 목표¶

    • 수치형 데이터와 범주형 데이터를 정확하게 구분할 수 있어요
    • 정형·반정형·비정형 데이터의 특징을 각각 설명할 수 있어요
    • 주어진 데이터셋에서 각 열(변수)의 데이터 유형을 분류할 수 있어요
    • 실제 데이터를 보고 어떤 데이터 종류인지 판단할 수 있어요

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    이전 장에서는 데이터가 무엇인지, 그리고 데이터 리터러시의 중요성을 배웠어요. 이번 장에서는 그런 데이터들이 어떤 종류인지, 어떤 형태를 가지고 있는지 알아보겠습니다. 혼자 읽어도 충분히 이해할 수 있도록 차근차근 설명해 드릴게요!

    💡 왜 이걸 배우나요?¶

    외국어 공부를 시작할 때, 먼저 명사, 동사, 형용사 같은 기본 문법을 배우지 않나요? 같은 이유로 데이터 분석을 시작하기 전에 데이터의 종류를 아는 것이 매우 중요합니다.

    데이터의 종류를 모르면: - 📊 어떤 분석 방법을 써야 하는지 몰라요 - 🤔 그래프를 어떻게 그려야 할지 헷갈려요 - ❌ 잘못된 결론을 내릴 수 있어요

    데이터 종류를 알면: - ✅ 올바른 분석 방법을 선택할 수 있어요 - ✅ 적절한 시각화를 만들 수 있어요 - ✅ 신뢰할 수 있는 결론에 도달할 수 있어요

    지금부터 함께 배워보겠습니다!

    📚 핵심 개념¶

    개념 1: 수치형(Numerical) vs 범주형(Categorical) 데이터¶

    🎯 비유로 시작해볼게요¶

    학교 급식 만족도 조사를 한다고 생각해봅시다.

    "오늘 급식이 몇 점인가요?" → 1점, 2점, 3점... 이렇게 숫자로 답해요 (수치형)

    "급식이 맛있었나요?" → "맛있어요", "보통이에요", "싫어요" 이렇게 카테고리로 답해요 (범주형)

    같은 주제인데 답변의 형태가 다르죠? 그게 바로 데이터 종류의 차이입니다!

    📖 정확한 정의¶

    수치형(Numerical) 데이터 - 정의: 숫자로 표현되며, 크기를 비교할 수 있는 데이터 - 특징: 더하기, 빼기, 평균 계산이 가능해요 - 예시: 키(cm), 점수(점), 나이(살), 판매액(원)

    범주형(Categorical) 데이터 - 정의: 정해진 카테고리(선택지) 중에 하나를 선택하는 데이터 - 특징: 순서가 있을 수도, 없을 수도 있어요 - 예시: 성별(남/녀), 혈액형(A/B/O/AB), 만족도(상/중/하)

    🔍 예시로 확인해보기¶

    급식 만족도 설문 데이터를 보세요:

    학생이름       급식점수    급식맛   식재료선호도
---------------------------------------------------------
김철수         4          맛있어요   싱거워요
이영희         5          맛있어요   자극적이어요
박민준         2          싫어요    싱거워요
    • 급식점수: 수치형 ✅ (4, 5, 2 → 숫자)
    • 급식맛: 범주형 ✅ ("맛있어요", "싫어요" → 정해진 선택지)
    • 식재료선호도: 범주형 ✅ (정해진 선택지 중 선택)

    💡 팁: "평균을 구할 수 있는가?"라고 자문해보세요! - 급식점수 평균: 3.67점 ✅ (평균 구하기 가능) - 급식맛 평균: ? ❌ ("맛있어요"의 평균은 말이 안 되지?)

    개념 2: 정형(Structured) 데이터¶

    🎯 비유로 이해하기¶

    학교 성적표를 생각해보세요. 📋

    이름 | 수학 | 영어 | 과학

    각 항목이 정해진 위치에 정확히 들어가 있어요. 이렇게 깔끔하게 정렬된 형태가 정형 데이터입니다.

    📖 정의와 특징¶

    정형 데이터: - 정의: 행(row)과 열(column)로 이루어진 표 형태의 데이터 - 특징: - 각 열의 이름(헤더)이 명확해요 - 데이터 타입이 정해져 있어요 - 분석하기 가장 쉬워요! - 예시: Excel 스프레드시트, 데이터베이스 테이블, CSV 파일

    🔍 정형 데이터 실제 모습¶

    고객ID    주문날짜      상품명      가격(원)
1001     2024-01-15    노트북      15000
1002     2024-01-16    펜         3000
1003     2024-01-17    지우개      2000

    정형의 장점: - 컴퓨터가 이해하기 쉬워요 ✅ - 빠르게 분석할 수 있어요 ✅ - 데이터 위치를 명확하게 알 수 있어요 ✅

    개념 3: 비정형(Unstructured) 데이터¶

    🎯 비유로 이해하기¶

    SNS에 올린 댓글을 생각해봅시다. 💬

    "오늘 영화 정말 재미있었어!!! 
친구들과 함께 봤는데 최고다!!"

    이건 표 형태가 아니에요. 글자가 자유롭게 흘러가죠? 이게 비정형 데이터입니다.

    📖 정의와 특징¶

    비정형 데이터: - 정의: 정해진 구조가 없는 자유로운 형태의 데이터 - 특징: - 텍스트, 이미지, 동영상, 음성 등 다양한 형태 - 사람이 읽기는 쉽지만 컴퓨터가 분석하기는 어려워요 - 더 정교한 분석 기술(AI/머신러닝)이 필요해요 - 예시: 블로그 포스트, 유튜브 댓글, 사진, 녹음 파일

    🔍 비정형 데이터 실제 예시¶

    • 텍스트: 영화 리뷰, 제품 후기, 뉴스 기사
    • 이미지: 인스타그램 사진, X레이 영상, 위성사진
    • 동영상: 유튜브 영상, 감시 카메라 영상
    • 음성: 통화 녹음, 팟캐스트

    비정형의 특징: - 인간다운 데이터 ✍️ (사람의 감정, 생각이 드러남) - 분석하기 어려움 🤔 (고급 기술 필요) - 엄청난 가치 💎 (사람의 진심이 담겨있음)

    개념 4: 반정형(Semi-structured) 데이터¶

    🎯 비유로 이해하기¶

    SNS 프로필을 생각해봅시다. 👤

    이름: 김철수
나이: 25세
거주지: 서울
자기소개: "안녕하세요! 저는 영화를 사랑하는 
평범한 직장인입니다. 함께 영화 이야기 나눠요!"

    일부는 정해진 형태(이름, 나이, 거주지)지만, 일부는 자유로운 형태(자기소개)예요. 이게 반정형입니다!

    📖 정의와 특징¶

    반정형 데이터: - 정의: 정형과 비정형의 중간 형태로, 일부는 구조화되고 일부는 자유로운 데이터 - 특징: - 메타데이터(데이터를 설명하는 데이터)가 있어요 - 구조가 있지만 완전히 규칙적이지는 않아요 - 정형과 비정형의 장점을 조금씩 가지고 있어요 - 예시: JSON 파일, XML 문서, 웹페이지 HTML, 이메일

    🔍 반정형 데이터 실제 예시¶

    JSON 형식 (가장 흔한 반정형): 

    {
  "고객명": "김철수",
  "나이": 28,
  "이메일": "kim@example.com",
  "리뷰": "상품이 정말 좋아요! 배송도 빨랐어요."
}

    구조가 있으면서도(고객명, 나이, 이메일), 자유로운 부분도 있어요(리뷰).

    🔨 따라하기: 실제 데이터 분류해보기¶

    Step 1: 준비물 확인하기¶

    이번 실습에서는 누구나 가지고 있는 도구만 사용해요: - 📝 종이와 펜 (또는 메모장) - 👀 집중력

    코드나 복잡한 프로그램은 필요 없어요!

    Step 2: 예시 데이터 읽어보기¶

    아래는 실제 병원 진료 데이터의 일부입니다. 천천히 읽어보세요.

    환자ID    나이    성별    진료과목    증상설명                    진료점수
P001     34     여     피부과     "얼굴에 여드름이 많아요"      5
P002     67     남     내과      "기침이 일주일째 계속"        3
P003     28     여     치과      "앞니가 빠졌어요"            2

    Step 3: 각 열을 분류하기¶

    환자ID: 숫자지만 평균을 구하지 않아요 → 범주형 ✅

    나이: 34, 67, 28 → 평균을 구할 수 있어요 → 수치형 ✅

    성별: "남", "여" → 정해진 선택지 → 범주형 ✅

    진료과목: "피부과", "내과", "치과" → 정해진 선택지 → 범주형 ✅

    증상설명: 자유로운 문장 → 비정형 데이터의 일부 ✅

    진료점수: 5, 3, 2 → 평균을 구할 수 있어요 → 수치형 ✅

    ✅ 체크포인트: 여기까지 이해가 되셨나요? 각 열을 보고 "이건 뭔가?"라고 자문하는 습관이 생겼다면 성공입니다!

    Step 4: 전체 데이터 형태 판단하기¶

    위 병원 진료 데이터는? - ✅ 행과 열로 이루어져 있고 - ✅ 각 열의 이름이 명확하고 - ✅ 규칙적인 구조를 가지고 있으므로

    → 정형 데이터 입니다! 📊

    Step 5: 비정형 데이터와 비교하기¶

    만약 같은 정보를 이렇게 표현했다면:

    "34살 여성 환자가 피부과에 방문했어요. 
'얼굴에 여드름이 많아서 고민이에요. 
뾰족한 게 나는데 아프기도 하고 화장하기도 힘들어요.'
라고 했어요. 진료 만족도는 5점입니다."

    이건 → 비정형 데이터 (자유로운 문장 형태)

    Step 6: 실습 마무리¶

    당신이 수집할 데이터들을 먼저 분류해보세요:

    • 📱 SNS 팔로워 수 → ? (수치형)
    • 👍 좋아요/싫어요 → ? (범주형)
    • 🎬 영화 리뷰 글 → ? (비정형)
    • 📧 이메일의 제목 + 본문 → ? (반정형)

    천천히 생각해보세요. 정답은 괄호 안에 있어요!

    ⚠️ 자주 하는 실수¶

    실수 1: "숫자 = 수치형" 이라고 생각하기¶

    ❌ 틀린 예시: 

    전화번호: 01012345678
학번: 2024001
우편번호: 06234

    이건 모두 숫자지만, 평균을 구할 수 있나요?

    "전화번호의 평균 = 01012345678이 말이 되나요?" → 아니에요!

    ✅ 올바른 이해: - 전화번호, 학번, 우편번호는 범주형 데이터입니다. - 왜냐하면 크기를 비교하거나 계산할 의미가 없거든요.

    핵심: "평균, 합계를 구할 수 있는가?"로 판단하세요!

    실수 2: 비정형 데이터를 "쓸모없다"고 생각하기¶

    ❌ 틀린 생각: "비정형 데이터는 분석하기 어려우니까 필요 없어!"

    ✅ 올바른 이해: 비정형 데이터는 엄청난 가치가 있어요! - 고객 만족도를 정확하게 알 수 있어요 - 제품 개선 아이디어를 찾을 수 있어요 - 경쟁사보다 먼저 시장 변화를 감지할 수 있어요

    핵심: 분석 방법만 다를 뿐, 가치는 더 클 수도 있어요!

    실수 3: 데이터 분류를 "절대적"이라고 생각하기¶

    ❌ 틀린 생각: "점수는 항상 수치형이고, 이름은 항상 범주형이야!"

    ✅ 올바른 이해: 상황에 따라 달라질 수 있어요!

    예를 들어: - 온라인 게임 랭킹 점수 → 10000점, 9500점 → 수치형 (순위 비교) - 만족도 점수 → 1점, 2점, 3점 → 보통 범주형 (만족도 카테고리)

    핵심: "어떤 목적으로 이 데이터를 사용할 건가?"를 먼저 생각하세요!

    데이터 종류 비교표¶

    수치형 vs 범주형:

    📊 수치형 데이터 - 숫자로 표현됨 (5, 3.5, -10) - 평균, 합계, 최댓값 계산 가능 - 예: 나이, 키, 판매액, 온도

    📁 범주형 데이터 - 정해진 선택지 중 선택 ("남", "여", "상") - 평균/합계 계산 불가능 - 예: 성별, 혈액형, 만족도 등급

    정형 vs 비정형:

    🗂️ 정형 데이터 - 행과 열의 표 형태 - 구조가 명확함 (Excel, 데이터베이스) - 분석 가장 쉬움

    📝 비정형 데이터 - 자유로운 형태 (텍스트, 이미지, 영상) - 구조가 불명확함 - 분석하려면 고급 기술 필요

    반정형 데이터:

    🔀 반정형 데이터 - 정형과 비정형의 중간 - 일부는 구조화, 일부는 자유로움 - 예: JSON, XML, HTML

    ✅ 스스로 점검해 봐요¶

    다음 질문에 "네"라고 답할 수 있으면 이 장을 완벽하게 이해한 거예요! 🎉

    • "키(cm)와 성별(남/녀)의 차이를 설명할 수 있나요?"
    • 키: 수치형 (평균을 구할 수 있음)

    • 성별: 범주형 (정해진 선택지)

    • "정형 데이터가 왜 분석하기 쉬운지 설명할 수 있나요?"

    • 구조가 명확하고, 규칙이 있어서 컴퓨터가 이해하기 쉬워요

    • "SNS 댓글을 어떤 종류의 데이터로 분류하나요?"

    • 비정형 데이터 (자유로운 문장)

    • "고객ID(001, 002, 003)는 수치형인가요?"

    • 아니요, 범주형입니다 (평균을 구할 의미가 없으므로)

    • "JSON 파일은 무엇인가요?"

    • 반정형 데이터 (일부 구조화, 일부 자유로움)

    📌 이 장의 핵심 정리¶

    ✅ 꼭 기억할 4가지¶

    1. 수치형 데이터 = 평균, 합계를 구할 수 있는 숫자 데이터 (나이, 점수)

    2. 범주형 데이터 = 정해진 선택지 중 고르는 데이터 (성별, 혈액형)

    3. 정형 데이터 = 깔끔한 표 형태 (Excel, 데이터베이스) ✨ 분석하기 가장 쉬움

    4. 비정형 데이터 = 자유로운 형태 (글, 사진, 영상) ✨ 가치는 크지만 분석 어려움
