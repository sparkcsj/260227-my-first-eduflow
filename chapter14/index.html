    Chapter 14. 데이터를 나누어 보기 — 그룹별 분석의 힘¶

    🎯 이 장의 학습 목표¶

    • pandas의 groupby()로 데이터를 그룹별로 묶고 집계할 수 있습니다
    • 오렌지3에서 Select Rows와 Group By 위젯으로 데이터를 필터링할 수 있습니다
    • 같은 데이터도 어떻게 나누느냐에 따라 완전히 다른 의미를 가질 수 있음을 경험합니다
    • 그룹별 분석으로 숨겨진 패턴을 찾을 수 있습니다

    예상 학습 시간: 약 120분

    📚 미리 알아야 할 것¶

    이 장을 시작하기 전에 확인해 주세요: - 이전 장에서 배운 것: pandas 기본 사용법(DataFrame 만들기, 열 선택, 기본 통계) - 준비물: Python(pandas), 오렌지3, 샘플 데이터셋

    💡 왜 이걸 배우나요?¶

    여기 흥미로운 이야기가 있습니다.

    학교 성적 평가 데이터를 모두 합쳐서 봤을 때 평균 점수는 남학생과 여학생이 똑같았습니다. 하지만 남학생과 여학생을 따로 나누어서 보니? 여학생이 모든 과목에서 더 높은 점수를 받았어요. 이런 현상을 심슨의 역설(Simpson's Paradox)이라고 부릅니다.

    이것이 바로 "데이터를 나누어 보기"가 중요한 이유입니다. 같은 데이터도 어떤 기준으로 쪼개느냐에 따라 완전히 다른 이야기를 들려줍니다.

    이 장에서는 데이터를 그룹별로 나누고, 각 그룹의 특성을 비교하고, 숨겨진 패턴을 발견하는 방법을 배워봅시다. 파이썬의 강력한 도구 groupby()와 시각적으로 쉬운 오렌지3를 함께 사용하면서요.

    📚 핵심 개념¶

    개념 1: groupby()의 의미 — "같은 것끼리 묶기"¶

    비유로 시작해요

    카페에서 주문을 받는 상황을 생각해 봅시다. - 아메리카노: 김철수, 이영희, 박민준 (3명) - 라떼: 최수진, 정민호 (2명)
    - 에스프레소: 박민준 (1명)

    같은 음료를 주문한 사람들끼리 묶으면, 각 음료별로 몇 명이 주문했는지 한눈에 보여요. 이게 바로 groupby()가 하는 일입니다!

    정확한 정의

    groupby()는 데이터프레임을 특정 열의 값에 따라 여러 개의 그룹으로 나누고, 각 그룹에 함수를 적용하여 집계된 결과를 반환하는 메서드입니다.

    원래 데이터 → [같은 값으로 묶기] → 그룹별 데이터 → [함수 적용] → 결과

    예시로 확인해요

    # 예: 학교 동아리별 활동 시간
동아리명        학생명      활동시간
---
축구부          김철수      8
배구부          이영희      6
축구부          박민준      9
배구부          최수진      7

    동아리명으로 groupby()하면? 

    축구부: [8, 9] → 합계 17시간, 평균 8.5시간
배구부: [6, 7] → 합계 13시간, 평균 6.5시간

    개념 2: 집계 함수 — "그룹별로 계산하기"¶

    정의: 각 그룹에 적용되는 계산 함수들입니다.

    자주 사용하는 함수들: - sum(): 그룹별 합계 - mean(): 그룹별 평균 - count(): 그룹별 개수 - max() / min(): 그룹별 최댓값 / 최솟값 - std(): 그룹별 표준편차

    동아리별_합계 = df.groupby('동아리명')['활동시간'].sum()
# 결과: 축구부 17, 배구부 13

동아리별_평균 = df.groupby('동아리명')['활동시간'].mean()
# 결과: 축구부 8.5, 배구부 6.5

    개념 3: 다중 그룹화 — "두 가지 기준으로 동시에 나누기"¶

    때로는 하나의 기준만으로는 부족합니다. 예를 들어 "학년별, 반별로 성적을 비교하고 싶다"면?

    # 학년과 반으로 동시에 묶기
df.groupby(['학년', '반'])['성적'].mean()

    이렇게 하면 1학년 1반, 1학년 2반, 2학년 1반... 이렇게 모든 조합별로 평균을 계산해줍니다.

    개념 4: 오렌지3의 시각적 필터링 — "마우스로 조건 만들기"¶

    정의: 코드를 쓰지 않고 위젯을 드래그하여 데이터를 필터링하고 그룹화하는 방식입니다.

    오렌지3의 Select Rows(조건 필터링)와 Group By(그룹 집계) 위젯을 사용하면, 파이썬과 같은 결과를 마우스 클릭만으로 얻을 수 있습니다.

    이건 나중에 실습에서 자세히 배워봅시다!

    🔧 직접 해봐요¶

    실습 1: 간단한 groupby() — 카페 음료 주문 분석¶

    목표: groupby()로 음료별 주문 개수와 평균 가격을 계산합니다

    준비물: Python, pandas

    따라하기:

    Step 1: 샘플 데이터 만들기

    import pandas as pd

# 카페 주문 데이터
data = {
    '음료명': ['아메리카노', '라떼', '아메리카노', '에스프레소', 
               '라떼', '아메리카노', '카푸치노', '라떼'],
    '가격': [3000, 4500, 3000, 3500, 4500, 3000, 4500, 4500],
    '판매량': [5, 3, 7, 2, 4, 6, 2, 3]
}

df = pd.DataFrame(data)
print(df)

    Step 2: 음료별로 묶고 평균 가격 계산하기

    # 음료명으로 그룹화하고 가격의 평균 계산
음료별_평균가격 = df.groupby('음료명')['가격'].mean()
print("\n=== 음료별 평균 가격 ===")
print(음료별_평균가격)

    Step 3: 음료별 판매량 합계 계산하기

    # 음료별 판매량 합계
음료별_판매량 = df.groupby('음료명')['판매량'].sum()
print("\n=== 음료별 총 판매량 ===")
print(음료별_판매량)

    Step 4: 한 번에 여러 통계 계산하기

    # 한 번에 여러 함수 적용
음료별_통계 = df.groupby('음료명')['판매량'].agg(['sum', 'mean', 'count'])
print("\n=== 음료별 통계 (합계, 평균, 종류) ===")
print(음료별_통계)

    ✅ 체크포인트: 여기까지 잘 되었다면 음료별로 묶인 통계 표가 보여야 해요!

    실습 2: 실제 데이터로 그룹별 분석하기 — 넷플릭스 콘텐츠 분석¶

    목표: 나라별로 넷플릭스 콘텐츠를 분석합니다

    준비물: Netflix 샘플 데이터

    따라하기:

    Step 1: 데이터 준비하기

    # 넷플릭스 콘텐츠 샘플
netflix_data = {
    '제목': ['Squid Game', 'Stranger Things', 'Money Heist', 
             'The Crown', 'Lupin', 'Witcher'],
    '국가': ['한국', '미국', '스페인', '영국', '프랑스', '폴란드'],
    '장르': ['드라마', '판타지', '드라마', '드라마', '드라마', '판타지'],
    '평점': [8.0, 8.7, 8.2, 8.6, 7.5, 8.2]
}

df_netflix = pd.DataFrame(netflix_data)
print(df_netflix)

    Step 2: 국가별 콘텐츠 개수 세기

    # 국가별 콘텐츠 개수
국가별_콘텐츠수 = df_netflix.groupby('국가').size()
print("\n=== 국가별 콘텐츠 개수 ===")
print(국가별_콘텐츠수)

    Step 3: 국가별 평균 평점 계산하기

    # 국가별 평균 평점
국가별_평균평점 = df_netflix.groupby('국가')['평점'].mean()
print("\n=== 국가별 평균 평점 ===")
print(국가별_평균평점)

    Step 4: 장르별로도 분석해보기

    # 장르별 콘텐츠 개수와 평균 평점
장르별_분석 = df_netflix.groupby('장르').agg({
    '제목': 'count',  # 콘텐츠 개수
    '평점': 'mean'    # 평균 평점
})
장르별_분석.columns = ['콘텐츠개수', '평균평점']
print("\n=== 장르별 분석 ===")
print(장르별_분석)

    ✅ 체크포인트: 각 국가별로 몇 개의 콘텐츠가 있고, 평점이 얼마인지 보이나요?

    📝 전체 코드¶

    여기 위의 실습을 한 번에 실행할 수 있는 완전한 코드입니다:

    import pandas as pd

# ===== 실습 1: 카페 음료 =====
print("★★★ 실습 1: 카페 음료 분석 ★★★\n")

data = {
    '음료명': ['아메리카노', '라떼', '아메리카노', '에스프레소', 
               '라떼', '아메리카노', '카푸치노', '라떼'],
    '가격': [3000, 4500, 3000, 3500, 4500, 3000, 4500, 4500],
    '판매량': [5, 3, 7, 2, 4, 6, 2, 3]
}
df = pd.DataFrame(data)

print("원본 데이터:")
print(df)

음료별_평균가격 = df.groupby('음료명')['가격'].mean()
print("\n음료별 평균 가격:")
print(음료별_평균가격)

음료별_통계 = df.groupby('음료명')['판매량'].agg(['sum', 'mean', 'count'])
음료별_통계.columns = ['총판매량', '평균', '등장횟수']
print("\n음료별 판매 통계:")
print(음료별_통계)

# ===== 실습 2: 넷플릭스 =====
print("\n\n★★★ 실습 2: 넷플릭스 콘텐츠 분석 ★★★\n")

netflix_data = {
    '제목': ['Squid Game', 'Stranger Things', 'Money Heist', 
             'The Crown', 'Lupin', 'Witcher'],
    '국가': ['한국', '미국', '스페인', '영국', '프랑스', '폴란드'],
    '장르': ['드라마', '판타지', '드라마', '드라마', '드라마', '판타지'],
    '평점': [8.0, 8.7, 8.2, 8.6, 7.5, 8.2]
}
df_netflix = pd.DataFrame(netflix_data)

print("원본 데이터:")
print(df_netflix)

국가별_분석 = df_netflix.groupby('국가').agg({
    '제목': 'count',
    '평점': 'mean'
})
국가별_분석.columns = ['콘텐츠개수', '평균평점']
print("\n국가별 분석:")
print(국가별_분석)

장르별_분석 = df_netflix.groupby('장르').agg({
    '제목': 'count',
    '평점': 'mean'
})
장르별_분석.columns = ['콘텐츠개수', '평균평점']
print("\n장르별 분석:")
print(장르별_분석)

    ⚠️ 자주 하는 실수¶

    실수 1: groupby()한 후에 열을 선택하지 않아서 에러가 나요¶

    증상: 

    df.groupby('음료명').mean()  # ❌ 에러 또는 예상과 다른 결과

    왜 이런 일이 생기나요?
    groupby() 후에 어떤 열에 함수를 적용할지 명시하지 않으면, pandas가 모든 수치형 열에 함수를 적용하려고 시도합니다. 가격 외에 판매량도 있으면 둘 다 계산하게 되어 혼란스러워요.

    이렇게 해결해요: 

    df.groupby('음료명')['가격'].mean()  # ✅ 가격만 선택

    기억하세요: groupby() → ['열이름'] → 함수() 순서!

    실수 2: 다중 열로 groupby할 때 괄호를 잘못 써요¶

    증상: 

    df.groupby('학년', '반')['성적'].mean()  # ❌ 에러

    왜 이런 일이 생기나요?
    두 개 이상의 열로 묶을 때는 반드시 대괄호와 쉼표로 리스트를 만들어야 합니다.

    이렇게 해결해요: 

    df.groupby(['학년', '반'])['성적'].mean()  # ✅ 대괄호로 감싸기

    실수 3: 결과를 데이터프레임이 아닌 Series로 받아서 추가 작업이 어려워요¶

    증상: 

    결과 = df.groupby('음료명')['가격'].mean()
# 이건 Series라 다른 열과 합치기 어려움

    왜 이런 일이 생기나요?
    하나의 열만 선택하면 Series가 반환되고, 여러 열을 선택하거나 agg()를 쓰면 DataFrame이 반환됩니다. 나중에 추가 작업이 필요하면 DataFrame이 편해요.

    이렇게 해결해요: 

    결과 = df.groupby('음료명').agg({'가격': 'mean'})  # ✅ DataFrame 반환
# 또는
결과 = df.groupby('음료명')[['가격']].mean()  # ✅ 대괄호 두 개

    # 콘텐츠 개수가 많은 국가 순으로 정렬
국가별_분석 = df_netflix.groupby('국가').size().sort_values(ascending=False)

    더하기 2: 필터링한 후 groupby하기

high_rated = df_netflix[df_netflix['평점'] >= 8.0]
print(high_rated.groupby('국가').size())

    더하기 3: 여러 함수를 한 번에 적용하기 

    df.groupby('음료명')['가격'].agg(['min', 'mean', 'max', 'std'])

    📌 이 장의 핵심 정리¶

    이 장에서 배운 가장 중요한 것들입니다:

    • ✅ groupby()의 힘: 같은 데이터도 어떻게 나누느냐에 따라 다른 이야기를 들려줍니다
    • ✅ 기본 문법: df.groupby('열').집계함수() 순서로 사용합니다
    • ✅ 다양한 함수: sum, mean, count, max, min, std 등을 상황에 맞게 선택합니다
    • ✅ 다중 그룹화: 여러 열로 동시에 묶을 때는 대괄호 안에 리스트로 넣습니다
