    Chapter 08: 파이썬으로 데이터 열어보기 — 판다스 첫걸음¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다: - [ ] pandas 라이브러리를 import하고 CSV 파일을 DataFrame으로 불러올 수 있어요 - [ ] head(), shape, info() 등의 메서드로 데이터 구조를 파악할 수 있어요 - [ ] 열(Column)과 행(Row)의 개념을 이해하고, 원하는 열을 선택할 수 있어요 - [ ] 데이터를 만났을 때 가장 먼저 해야 할 일들을 알 수 있어요

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    지난 chapter에서 배운 내용이 도움이 돼요: - 파이썬 기본 문법 (import, 변수 할당) - 엑셀에서 CSV 파일로 저장하는 방법 - 공공 데이터 다운로드하기

    💡 왜 이걸 배우나요?¶

    여러분이 데이터 분석을 하려면 먼저 데이터를 파이썬으로 열어야 합니다. 엑셀로 열 수도 있지만, 수백만 줄의 데이터를 만나면 엑셀은 느려집니다. 파이썬의 pandas라는 도구는 "데이터 전용 엑셀"이라고 생각하면 됩니다. 빠르고, 강력하고, 프로그래밍처럼 자동화할 수 있거든요.

    이 장에서 배우는 기초 기술들이 모든 데이터 분석의 출발점입니다. 데이터를 제대로 '만나는' 능력이 없으면, 분석도 시작할 수 없습니다.

    📚 핵심 개념¶

    개념 1: pandas란 무엇인가?¶

    비유로 시작
    pandas를 "엑셀의 파이썬 버전"이라고 생각해보세요. 엑셀은 마우스로 클릭하며 데이터를 조작하고, pandas는 코드로 데이터를 조작합니다. 그런데 pandas가 훨씬 빠르고, 더 강력해요.

    정확한 정의
    pandas는 Python Data Analysis Library의 약자로, 구조화된 데이터(표 모양의 데이터)를 다루는 전문 라이브러리입니다. CSV, 엑셀, 데이터베이스 등 여러 형태의 데이터를 쉽게 불러올 수 있습니다.

    예시로 확인

    import pandas as pd

# CSV 파일을 판다스로 열기
df = pd.read_csv('data.csv')

    이 3줄의 코드로 데이터를 파이썬에 불러올 수 있어요. 엑셀에서는 마우스로 파일을 열어야 하지만, pandas는 코드 한 줄이면 됩니다.

    개념 2: DataFrame이 뭐예요?¶

    비유로 시작
    DataFrame은 "파이썬 속의 표"라고 생각하세요. 행(row)과 열(column)로 이루어진 엑셀 표와 똑같은 구조인데, 파이썬에서 다룰 수 있도록 만든 거예요.

    정확한 정의
    DataFrame은 pandas의 핵심 자료구조입니다. 행 번호(index), 열 이름(columns), 그리고 그 교점에 있는 데이터(values)로 구성돼요.

    예시로 확인

         이름   나이   점수
0   김철수   25   85
1   이영희   28   90
2   박민준   26   88

    이 표에서: - 행(Row): 각 사람의 데이터 (0번 행은 김철수의 정보) - 열(Column): 같은 종류의 정보 모음 ('이름' 열, '나이' 열, '점수' 열) - 값(Value): 표의 각 칸 (김철수의 나이는 25)

    개념 3: CSV 파일이란?¶

    비유로 시작
    CSV는 "엑셀을 단순하게 저장한 것"입니다. 엑셀 파일(.xlsx)은 색깔, 폰트, 그래프 등 많은 정보를 담지만, CSV는 순수한 데이터만 담아요.

    정확한 정의
    CSV는 Comma-Separated Values의 약자로, 쉼표(,)로 구분된 텍스트 파일입니다.

    예시로 확인
    엑셀의 표를 CSV로 저장하면 이렇게 됩니다:

    이름,나이,점수
김철수,25,85
이영희,28,90
박민준,26,88

    순수한 텍스트일 뿐이지만, pandas는 이를 읽어서 정렬, 필터링, 통계 계산 등을 모두 할 수 있어요.

    개념 4: head(), shape, info()의 역할¶

    첫 인상이 중요한 이유
    새로운 데이터를 만났을 때, 가장 먼저 해야 할 일은 "이 데이터가 어떻게 생겼는지 확인"하는 것입니다. 크기는 몇 줄인지, 열은 뭐가 있는지, 데이터 타입은 뭔지 알아야 다음 단계로 나갈 수 있어요.

    세 가지 필수 메서드

    df.head()
    상위 5줄(기본값)을 보여줍니다. 전체 데이터가 너무 크면 모든 걸 출력할 수 없으니까요.

    df.head()  # 위의 5줄 확인
df.head(3)  # 위의 3줄 확인

    df.shape
    (행의 개수, 열의 개수) 형태로 데이터 크기를 알려줍니다.

    df.shape  # (100, 5) 라고 나오면 100줄, 5개 열

    df.info()
    각 열의 이름, 데이터 타입, null 값 개수를 자세히 보여줍니다.

    df.info()  # 모든 열 정보 한눈에 보기

    🔧 따라하기¶

    Step 1: pandas 설치 및 import하기¶

    먼저 pandas가 설치되어 있는지 확인해볼게요. 만약 설치되지 않았다면 터미널에서 이 명령어를 입력하세요:

    pip install pandas

    그 다음, 파이썬 파일을 열고 이렇게 입력하세요:

    import pandas as pd

    이 문장의 의미
    "pandas 라이브러리를 불러와서, 앞으로는 'pd'라고 부르겠다"는 뜻입니다. 매번 pandas를 쓸 때마다 'pd'라고 쓰면 되니까 편하죠.

    ✅ 체크포인트: 코드를 실행했을 때 에러가 안 나면 성공입니다!

    Step 2: 데이터 불러오기¶

    Chapter 07에서 다운로드한 CSV 파일을 pandas로 열어봅시다.

    df = pd.read_csv('data.csv')

    이 문장의 의미
    "data.csv 파일을 읽어서, df라는 변수에 저장하겠다"는 뜻입니다.

    중요한 팁: CSV 파일이 파이썬 파일과 같은 폴더에 있어야 해요. 다른 폴더에 있으면 전체 경로를 써야 합니다:

    df = pd.read_csv('/Users/myname/Desktop/data.csv')  # Mac
df = pd.read_csv('C:\\Users\\myname\\Desktop\\data.csv')  # Windows

    ✅ 체크포인트: 파일 경로에 오류가 없다면, df 변수가 생성됐을 거예요!

    Step 3: 데이터의 첫인상 확인하기¶

    데이터를 불러온 후 가장 먼저 할 일은 "어떤 모양인지 보기"예요.

    # 처음 5줄 보기
df.head()

    실행하면 이런 식으로 보일 거예요:

         이름   나이   점수
0   김철수   25   85
1   이영희   28   90
2   박민준   26   88
3   정수현   27   92
4   최지은   24   78

    왼쪽의 0, 1, 2... 숫자들은 인덱스(행 번호)입니다. 자동으로 붙어요.

    ✅ 체크포인트: 표 형태의 데이터가 보이면 성공! 기뻐하세요 🎉

    Step 4: 데이터 크기 파악하기¶

    # 크기 확인
print(df.shape)

    만약 데이터가 1000줄, 5개 열이면:

    (1000, 5)

    이라고 출력돼요. 이제 "어, 이 데이터는 작네" 또는 "와, 꽤 크네"라고 판단할 수 있어요.

    ✅ 체크포인트: (숫자, 숫자) 형태로 나왔나요? 맞으면 성공!

    Step 5: 열 정보 자세히 보기¶

    # 열의 이름, 타입, null 값 확인
df.info()

    출력 예시:

    <class 'pandas.core.frame.DataFrame'>
RangeIndex: 4 entries, 0 to 3
Data columns (total 3 columns):
 #   Column  Non-Null Count  Dtype  
---  -------  --------------  ------  
 0   이름      4 non-null      object 
 1   나이      4 non-null      int64  
 2   점수      4 non-null      float64
dtypes: float64(1), int64(1), object(1)

    이것은 다음을 의미합니다: - 총 4줄의 데이터 - 3개의 열 - 각 열의 데이터 타입 (object = 문자, int64 = 정수, float64 = 실수) - null값(빈 칸)이 없다

    ✅ 체크포인트: 테이블 형태의 정보가 나왔으면 완벽해요!

    Step 6: 특정 열 선택하기¶

    이제 특정 열을 꺼내보세요. 영어 문장처럼 생각하면 쉬워요:

    # "데이터프레임에서 '이름' 열을 꺼내줘"
df['이름']

    출력:

    0    김철수
1    이영희
2    박민준
3    정수현
Name: 이름, dtype: object

    또는 여러 열을 한 번에:

    # "데이터프레임에서 '이름'과 '점수' 열을 꺼내줘"
df[['이름', '점수']]

    출력:

         이름   점수
0   김철수   85
1   이영희   90
2   박민준   88
3   정수현   92

    ✅ 체크포인트: 원하는 열만 나왔나요? 그럼 완성입니다!

    📝 전체 코드¶

    지금까지 배운 내용을 한 파일에 정리했어요. 이 코드를 실행하면 데이터가 어떤 식으로 변하는지 한눈에 볼 수 있습니다:

    # 1단계: 라이브러리 불러오기
import pandas as pd

# 2단계: CSV 파일 읽기
df = pd.read_csv('data.csv')

# 3단계: 첫 5줄 보기
print("=== 데이터 첫인상 ===")
print(df.head())

# 4단계: 크기 확인
print("\n=== 데이터 크기 ===")
print(f"행의 개수: {df.shape[0]}, 열의 개수: {df.shape[1]}")

# 5단계: 상세 정보
print("\n=== 데이터 타입 정보 ===")
df.info()

# 6단계: 특정 열 선택
print("\n=== 이름 열만 추출 ===")
print(df['이름'])

# 보너스: 여러 열 선택
print("\n=== 이름과 점수만 추출 ===")
print(df[['이름', '점수']])

    💡 팁: 이 코드를 복사해서 여러분의 데이터로 바로 실행해볼 수 있어요!

    ⚠️ 자주 하는 실수¶

    실수 1: 파일을 찾을 수 없다는 에러¶

    에러 메시지: 

    FileNotFoundError: [Errno 2] No such file or directory: 'data.csv'

    왜 이런 일이 생기나요?
    CSV 파일이 파이썬 파일과 다른 폴더에 있거나, 파일 이름을 잘못 적었을 수 있어요.

    이렇게 해결해요: 1. 파이썬 파일과 CSV 파일을 같은 폴더에 옮기기 2. 또는 전체 경로를 정확하게 쓰기: pd.read_csv('/Users/name/Documents/data.csv') 3. 파일 이름의 띄어쓰기, 대소문자도 정확하게 확인하기

    실수 2: df['열이름']에서 따옴표를 빠뜨렸어요¶

    잘못된 코드: 

    df[이름]  # ❌ 에러 발생!

    올바른 코드: 

    df['이름']  # ✅ 맞아요!

    왜 이런 일이 생기나요?
    파이썬에서 따옴표 없이 쓰면 변수 이름으로 인식하기 때문에 에러가 나요.

    이렇게 해결해요: - 열이름은 항상 따옴표(' ' 또는 " ")로 감싸기 - 여러 열을 선택할 때는 대괄호 안에 리스트 사용: df[['열1', '열2']]

    실수 3: head()와 head(5)를 혼동했어요¶

    헷갈리기 쉬운 부분: 

    df.head()    # 기본적으로 위 5줄
df.head(10)  # 위 10줄
df.head(3)   # 위 3줄

    왜 이런 일이 생기나요?
    head()는 숫자를 생략하면 자동으로 5줄만 보여주는데, 필요에 따라 숫자를 넣을 수 있어서 헷갈릴 수 있어요.

    이렇게 해결해요: - 기본값(5줄)이 필요하면 df.head() - 다른 줄 수를 보고 싶으면 df.head(원하는_숫자)

    📌 이 장의 핵심 정리¶

    • ✅ pandas는 "데이터 전용 엑셀" — 파이썬으로 표 모양의 데이터를 다룬다
    • ✅ DataFrame은 "파이썬 속의 표" — 행, 열, 값으로 이루어져 있다
    • ✅ 새 데이터를 만났을 때는 세 단계: head() → shape → info() — 이것이 데이터 분석의 출발점이다
    • ✅ df['열이름']으로 원하는 열을 선택한다 — 따옴표를 빠뜨리면 안 된다
