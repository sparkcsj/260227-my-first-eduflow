    Chapter 09. 지저분한 데이터 깔끔하게 — 데이터 정제 실습¶

    🎯 이 장의 학습 목표¶

    • 결측값(빈 데이터)을 찾아내고 pandas로 처리할 수 있어요
    • 중복된 데이터를 탐지하고 제거할 수 있어요
    • 정제 전후의 데이터를 비교하여 정제의 중요성을 이해해요
    • 상황에 맞는 정제 전략을 선택할 수 있어요

    ⏱️ 예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    이전 장들에서 배운 내용을 간단히 복습해요:

    • pandas와 DataFrame: 데이터를 표처럼 다루는 도구예요
    • 기본 데이터 구조: 행(row), 열(column), 셀(cell)이 무엇인지 알고 있으면 좋아요
    • df.head(), df.info() 사용법: 데이터의 첫 모습을 보고 정보를 확인하는 방법이요

    혹시 이 내용들이 낯설다면 Chapter 07, 08을 다시 한 번 훑어보고 와도 좋습니다! 😊

    💡 왜 이걸 배우나요?¶

    현실의 데이터는 교과서처럼 완벽하지 않아요. 마치 번역 원고에 오탈자가 섞여 있어서 직접 수정해야 하는 것처럼, 데이터도 다음과 같은 문제를 가지고 있죠:

    • 📭 빈 칸 (결측값): 고객이 나이를 입력하지 않음
    • 🔄 중복된 정보: 같은 주문이 2번 기록됨
    • 🤔 잘못된 값: "나이: -5세" 같은 말도 안 되는 데이터

    만약 이런 "쓰레기" 데이터를 그대로 분석하면 어떻게 될까요?

    예시: 50명의 고객 나이 데이터 중 10명이 빠져있다면? - 평균 나이를 계산할 때 잘못된 결과가 나와요 - 의사결정을 했을 때 틀린 결론에 도달할 수 있어요

    바로 이것이 "Garbage In, Garbage Out" (쓰레기가 들어가면 쓰레기가 나온다!)이라는 원칙이에요.

    📚 핵심 개념¶

    개념 1: 결측값(Missing Values)이란?¶

    쉽게 말하면: 데이터가 없는 칸이에요.

    현실 예시를 생각해 봐요: - 온라인 쇼핑몰 회원가입 폼에서 "휴대폰 번호" 칸을 비우고 제출한 경우 - 설문조사 중간에 응답을 멈춘 경우 - 센서가 고장 나서 어떤 날씨 데이터가 기록되지 않은 경우

    pandas에서 결측값 표현: - NaN (Not a Number): 숫자 데이터에서 빈 칸 - None: 다른 타입 데이터에서 빈 칸 - 둘 다 "데이터가 없다"는 뜻이에요

    확인하는 방법:

    import pandas as pd

# 결측값이 있는 예시 데이터
data = {
    '이름': ['김철수', '이영희', None, '박민준'],
    '나이': [25, None, 28, 32],
    '도시': ['서울', '부산', '대구', None]
}
df = pd.DataFrame(data)

# 결측값 확인하기
print(df.isnull())        # True/False로 표시
print(df.isnull().sum())  # 각 열의 결측값 개수

    출력 결과: 

       이름   나이   도시
0  False False False
1  False True False
2  True  False False
3  False False True

이름    1
나이    1
도시    1

    개념 2: 중복 데이터(Duplicates)¶

    쉽게 말하면: 같은 정보가 여러 번 반복된 거예요.

    현실 예시: - 시스템 오류로 같은 주문이 2번 저장됨 - 여러 DB를 합칠 때 같은 사람 정보가 겹침 - 데이터 입력 시 실수로 같은 줄을 복사함

    생각해보기: 중복된 데이터가 있으면? - 매출을 계산할 때 실제보다 높게 나와요 - 고객 수를 셀 때 잘못된 숫자가 나와요

    개념 3: 결측값 처리 전략¶

    결측값을 발견했을 때, 우리는 3가지 선택을 할 수 있어요:

    전략 1️⃣ - 행 제거하기 (dropna) - 빈 칸이 있는 행 전체를 삭제해요 - 언제 쓸까? 중요한 열에 데이터가 빠졌을 때 - 주의! 데이터를 잃게 돼요

    전략 2️⃣ - 값 채우기 (fillna) - 빈 칸에 평균값, 최빈값, 또는 특정 값을 넣어요 - 언제 쓸까? 일부 데이터만 빠졌을 때 - 예: 나이 평균이 30세이면 빠진 나이를 30으로 채우기

    전략 3️⃣ - 그대로 두기 - 결측값의 의미가 있을 수 있어요 - 언제 쓸까? "응답 안 함"이 중요한 정보일 때

    개념 4: 중복 제거 (drop_duplicates)¶

    # 중복 행 제거
df_clean = df.drop_duplicates()

# 특정 열 기준으로만 중복 제거
df_clean = df.drop_duplicates(subset=['이름'])

    🎯 준비하기¶

    먼저 실습용 데이터셋을 만들어요. 의도적으로 결측값과 중복이 포함되어 있어요.

    import pandas as pd
import numpy as np

# 실습용 데이터 만들기
customers = {
    '고객ID': [1, 2, 3, 4, 5, 6, 7, 8],
    '이름': ['김철수', '이영희', '박민준', '최수영', '김철수', None, '신준호', '윤지현'],
    '나이': [25, None, 28, 32, 25, 29, None, 31],
    '구매액': [50000, 120000, np.nan, 80000, 50000, 95000, 75000, 110000],
    '가입지': ['서울', '부산', '대구', '인천', '서울', '부산', '서울', None]
}

df = pd.DataFrame(customers)
print("=== 정제 전 데이터 ===")
print(df)

    Step 1️⃣: 결측값 확인하기¶

    # 1단계: 결측값 시각화
print("\n=== 결측값 위치 확인 ===")
print(df.isnull())

# 2단계: 결측값 개수 세기
print("\n=== 각 열의 결측값 개수 ===")
print(df.isnull().sum())

# 3단계: 전체 결측값 비율 (%)
print("\n=== 결측값 비율 ===")
print((df.isnull().sum() / len(df) * 100).round(2))

    결과: 

       고객ID  이름   나이    구매액   가입지
0  False False False False False
1  False False True False False
2  False False False True False
...

고객ID      0
이름        1
나이        2
구매액       1
가입지       1

    💡 이게 무슨 뜻이냐면: 나이 열에는 2개, 구매액에는 1개의 빈 칸이 있다는 거예요!

    Step 2️⃣: 중복 데이터 찾기¶

    # 중복 행 찾기
print("\n=== 중복된 행 찾기 ===")
print(df.duplicated())

# 어떤 행이 중복인지 확인
print("\n=== 중복된 모든 행 보기 ===")
print(df[df.duplicated(keep=False)])

# 특정 열 기준으로만 중복 확인
print("\n=== '이름'으로만 중복 확인 ===")
print(df[df.duplicated(subset=['이름'], keep=False)])

    결과: 

    고객ID        이름  나이     구매액   가입지
0      1    김철수  25.0  50000.0   서울
4      5    김철수  25.0  50000.0   서울

    💡 발견! 김철수 고객이 정확히 같은 정보로 2번 기록되어 있어요.

    Step 3️⃣: 행 제거하기 (dropna 사용)¶

    결측값이 있는 행을 통째로 삭제하는 방법이에요.

    # 방법 1: 모든 결측값을 포함한 행 제거
df_drop1 = df.dropna()
print("=== dropna() 후 ===")
print(f"행의 개수: {len(df)} → {len(df_drop1)}")
print(df_drop1)

    결과: 

    행의 개수: 8 → 4
   고객ID   이름  나이      구매액   가입지
0       1  김철수  25.0  50000.0    서울
3       4  최수영  32.0  80000.0    인천
6       7  신준호  NaN  75000.0    서울

    ⚠️ 주의! 데이터가 절반 이상 사라졌어요. 이게 항상 좋은 방법은 아니에요.

    더 똑똑한 방법 - 특정 열만 확인하기:

    # 중요한 열만 기준으로 행 제거
df_drop2 = df.dropna(subset=['이름', '구매액'])
print("=== 중요한 열만 기준으로 제거 ===")
print(f"행의 개수: {len(df)} → {len(df_drop2)}")
print(df_drop2)

    결과: 

    행의 개수: 8 → 6

    ✅ 훨씬 낫다! 필요한 열의 데이터만 있으면 되니까 데이터 손실이 적어요.

    Step 4️⃣: 값 채우기 (fillna 사용)¶

    결측값을 특정 값으로 채우는 방법이에요.

    # 방법 1: 특정 값으로 채우기
df_fill1 = df.fillna({
    '나이': df['나이'].mean(),      # 평균값
    '구매액': 0,                     # 0으로
    '가입지': '미등록'               # 문자열
})

print("=== fillna로 값 채우기 ===")
print(df_fill1)

    결과: 

       고객ID   이름    나이     구매액   가입지
0       1  김철수  25.0  50000.0    서울
1       2  이영희  27.5 120000.0    부산
2       3  박민준  28.0    NaN    대구
4       5  김철수  25.0  50000.0    서울
5       6    미등록  29.0  95000.0    부산

    💡 팁! 숫자는 평균/중앙값으로, 문자는 특정 값으로 채우면 자연스러워요.

    Step 5️⃣: 중복 제거하기¶

    # 중복 행 제거
df_no_dup = df.drop_duplicates()
print("=== drop_duplicates() 후 ===")
print(f"행의 개수: {len(df)} → {len(df_no_dup)}")
print(df_no_dup)

    결과: 

    행의 개수: 8 → 7

    Step 6️⃣: 모두 함께 정제하기¶

    실무에서는 여러 단계를 함께 진행해요.

    # 정제 프로세스
df_clean = (df
    .dropna(subset=['이름', '구매액'])           # 중요 열의 결측값 제거
    .drop_duplicates(subset=['고객ID'])         # 중복 제거
    .fillna({'나이': df['나이'].mean()})         # 나머지 결측값 채우기
    .reset_index(drop=True)                      # 인덱스 초기화
)

print("=== 최종 정제 데이터 ===")
print(df_clean)
print(f"\n최종 행 개수: {len(df_clean)}")
print(f"남은 결측값: {df_clean.isnull().sum().sum()}개")

    결과: 

       고객ID   이름    나이     구매액   가입지
0       1  김철수  25.0  50000.0    서울

    ✅ 완벽해! 결측값도 없고 중복도 없어요.

    📝 전체 코드 (복사해서 바로 실행하세요!)¶

    import pandas as pd
import numpy as np

# ==================== 1단계: 데이터 준비 ====================
customers = {
    '고객ID': [1, 2, 3, 4, 5, 6, 7, 8],
    '이름': ['김철수', '이영희', '박민준', '최수영', '김철수', None, '신준호', '윤지현'],
    '나이': [25, None, 28, 32, 25, 29, None, 31],
    '구매액': [50000, 120000, np.nan, 80000, 50000, 95000, 75000, 110000],
    '가입지': ['서울', '부산', '대구', '인천', '서울', '부산', '서울', None]
}

df = pd.DataFrame(customers)
print("=" * 40)
print("정제 전 데이터")
print("=" * 40)
print(df)
print(f"\n결측값 개수:\n{df.isnull().sum()}")

# ==================== 2단계: 정제 ====================
df_clean = (df
    .dropna(subset=['이름', '구매액'])
    .drop_duplicates()
    .fillna({'나이': df['나이'].mean()})
    .reset_index(drop=True)
)

print("\n" + "=" * 40)
print("정제 후 데이터")
print("=" * 40)
print(df_clean)
print(f"\n결측값 개수:\n{df_clean.isnull().sum()}")

# ==================== 3단계: 비교 ====================
print("\n" + "=" * 40)
print("정제 효과")
print("=" * 40)
print(f"행의 개수: {len(df)} → {len(df_clean)}")
print(f"데이터 유지율: {len(df_clean)/len(df)*100:.1f}%")

    ⚠️ 자주 하는 실수¶

    실수 1️⃣: dropna()를 무분별하게 사용하기¶

    잘못된 예: 

    df_bad = df.dropna()  # ❌ 너무 많은 데이터가 사라져요!

    왜 이런 일이 생기나요? - 하나의 빈 칸만 있어도 전체 행이 삭제돼요 - 소중한 데이터를 잃게 돼요

    올바른 해결법: 

    # ✅ 꼭 필요한 열만 지정하기
df_good = df.dropna(subset=['이름', '구매액'])

    실수 2️⃣: fillna() 후 검토하지 않기¶

    잘못된 예: 

    df_filled = df.fillna(0)  # 무턱대고 0으로 채우기
# 나이가 0세인 사람이 생김 (말도 안 돼!)

    올바른 해결법: 

    # ✅ 열의 특성에 맞게 채우기
df_filled = df.fillna({
    '나이': df['나이'].mean(),      # 평균값이 합리적
    '구매액': 0,                     # 구매 없음 = 0
    '이름': '미입력'                 # 분류형으로 명확하게
})

# ✅ 결과 확인하기
print(df_filled.isnull().sum())

    실수 3️⃣: 정제 전후를 비교하지 않기¶

    문제점: 

    df_clean = df.dropna().drop_duplicates()
# 뭘 했는지 모르는 상태로 분석 시작 💫

    올바른 해결법: 

    # ✅ 정제 내역 기록하기
print(f"정제 전: {len(df)}행")
df_clean = df.dropna(subset=['구매액']).drop_duplicates()
print(f"정제 후: {len(df_clean)}행")
print(f"제거된 행: {len(df) - len(df_clean)}행")

# ✅ 어떤 데이터가 제거됐는지 확인
removed = df[~df.index.isin(df_clean.index)]
print("\n제거된 데이터:")
print(removed)

    다음 질문에 답할 수 있나요? (혼자 생각해 본 후 아래 답을 확인하세요)

    Q1: 결측값(NaN)과 None의 차이는 뭘까요?

    👉 답 보기 pandas에서는 둘 다 "데이터 없음"을 의미합니다. - `NaN`: 주로 숫자 데이터에서 사용 - `None`: 다른 타입에서 사용 하지만 pandas는 내부적으로 둘 다 `NaN`으로 통일해서 처리해요. 우리는 `isnull()` 메서드로 둘 다 찾아낼 수 있어요.

    Q2: df.dropna()와 df.dropna(subset=['이름'])의 차이는?

    👉 답 보기 - `df.dropna()`: 어떤 열이든 하나라도 빈 칸이 있으면 행 전체 삭제 - `df.dropna(subset=['이름'])`: '이름' 열에만 빈 칸이 있으면 행 삭제, 다른 열은 상관없음 두 번째가 더 똑똑한 선택입니다! 데이터 손실이 적거든요.

    Q3: 어떤 상황에서는 결측값을 그대로 두는 게 나을까요?

    👉 답 보기 "응답 안 함"이 의미 있는 정보일 때입니다. 예: 설문조사에서 "정치 성향" 질문을 건너뛴 것 - 이는 "중립적"일 수도 있고 "응답 거부"일 수도 있어요 - 0이나 "무응답"으로 채우면 의미가 달라져요 - 때론 그냥 NaN으로 두고 분석할 때 따로 처리하는 게 맞아요

    도전 3️⃣: 정제 함수 만들기¶

    자주 쓰는 정제 과정을 함수로 만들어보세요.

    def clean_data(df, drop_cols=None, dup_cols=None, fill_cols=None):
    """
    데이터 정제 함수
    - drop_cols: dropna할 열
    - dup_cols: 중복 제거 기준 열
    - fill_cols: fillna할 열과 값 (딕셔너리)
    """
    df_clean = df.copy()

    if drop_cols:
        df_clean = df_clean.dropna(subset=drop_cols)

    if dup_cols:
        df_clean = df_clean.drop_duplicates(subset=dup_cols)
    else:
        df_clean = df_clean.drop_duplicates()

    if fill_cols:
        df_clean = df_clean.fillna(fill_cols)

    return df_clean.reset_index(drop=True)

# 사용 예
df_final = clean_data(
    df, 
    drop_cols=['이름', '구매액'],
    dup_cols=['고객ID'],
    fill_cols={'나이': df['나이'].mean()}
)
