    Chapter 10. 여기까지 정리 — 나만의 데이터셋 만들기 프로젝트¶

    🎯 이 장의 학습 목표¶

    • 관심 있는 주제를 선정하고 데이터 수집 계획을 세울 수 있습니다
    • 구글 설문지 또는 공공 데이터에서 데이터를 직접 수집할 수 있습니다
    • 수집한 데이터를 pandas로 불러와 정제하고 저장할 수 있습니다
    • 데이터 수집·정제 과정을 단계별로 정리하여 발표할 수 있습니다

    예상 학습 시간: 약 3시간 (데이터 수집 시간 포함)

    📚 미리 알아야 할 것¶

    Part 2에서 배운 내용을 잠깐 떠올려봐요:

    • CSV 파일 읽고 쓰기: pd.read_csv(), df.to_csv()
    • 데이터 구조 파악: df.head(), df.info(), df.describe()
    • 결측값 처리: df.isnull(), df.fillna(), df.dropna()
    • 데이터 정제: 컬럼명 정리, 중복값 제거, 데이터 타입 변환

    이 장에서는 이 모든 기술을 한 번에 사용해서 실제 프로젝트를 완성합니다. 걱정하지 마세요. 차근차근 안내해드릴게요! 🚀

    💡 왜 이걸 배우나요?¶

    데이터 분석의 첫 번째 단계는 "데이터를 모으는 것"입니다. 하지만 데이터를 모으기만 해서는 부족해요. 그 데이터가 정말 믿을 만한지, 제대로 정리되어 있는지 확인해야 합니다.

    예를 들어볼게요:

    우리 반 학생들의 "좋아하는 음식" 설문을 했는데, 누군가는 "치킨"이라고, 누군가는 "치킨 🍗"라고, 또 누군가는 "치 킨"이라고 적었어요. 컴퓨터 입장에서는 이 셋이 다른 데이터예요. 이걸 모두 "치킨"으로 통일해야 정확하게 분석할 수 있어요!

    이 프로젝트를 통해 여러분은:

    1. 데이터가 어디서 나오는지 알게 됩니다
    2. 현실의 데이터는 늘 지저분하다는 걸 체험합니다
    3. 정제된 데이터가 얼마나 소중한지 이해합니다
    4. 나만의 데이터셋 포트폴리오를 만들 수 있습니다

    📚 핵심 개념¶

    개념 1: 데이터 수집 전략 (Data Collection Strategy)¶

    비유: 요리사가 요리를 시작하기 전에 재료를 어디서 구할지, 얼마나 많이 필요한지 계획하는 것처럼, 데이터 분석도 먼저 어떤 데이터를 어떻게 모을지 계획해야 합니다.

    정의: 데이터 수집 전략이란 분석의 목표에 맞게 언제, 어디서, 누구로부터, 어떻게 데이터를 모을지 결정하는 과정입니다.

    구체적으로 생각해볼 것들:

    • 주제: 무엇에 대해 알고 싶은가? ("우리 반의 취미", "지역별 카페 가격", "유튜브 구독자 수" 등)
    • 대상(샘플): 누구의 데이터인가? ("우리 반 학생 30명", "서울의 카페 50개", "한국 유튜버 100명" 등)
    • 수집 방법: 어떻게 모을 것인가? (설문지, 웹 크롤링, 공공 데이터, 직접 측정 등)
    • 데이터 항목: 어떤 정보를 모을 것인가? (이름, 나이, 선택지, 의견 등)

    개념 2: 데이터 정제 (Data Cleaning)¶

    비유: 야채를 요리하기 전에 흙을 씻고, 상한 부분을 제거하고, 크기를 통일하는 것처럼, 수집한 데이터도 정리 작업을 거쳐야 합니다.

    정의: 데이터 정제란 수집한 원본 데이터(Raw Data)에서 오류, 결측값, 중복값, 불일치를 발견하고 수정하여 분석에 적합한 상태로 만드는 과정입니다.

    주요 정제 작업:

    • 결측값 처리: 비어 있는 칸을 채우거나 제거
    • 중복값 제거: 같은 응답이 여러 번 들어온 경우 제거
    • 데이터 타입 통일: 날짜, 숫자, 텍스트 형식을 맞춤
    • 이상값 검출: "나이: 999세" 같은 말도 안 되는 값 발견
    • 텍스트 정규화: "치킨" "치킨 " "CHICKEN" → 모두 "치킨"으로 통일

    개념 3: 공공 데이터 (Open Data) 활용¶

    비유: 도서관의 책처럼, 정부나 기관에서 만든 데이터를 누구나 자유롭게 사용할 수 있습니다.

    정의: 공공 데이터는 정부, 지자체, 공공기관이 공개한 데이터로, 누구나 다운로드받아 분석할 수 있습니다. 이미 정리되어 있는 경우가 많아 초보자가 사용하기 좋습니다.

    주요 공공 데이터 사이트:

    • 데이터.go.kr (한국 정부 공공데이터 포털)
    • 서울 열린데이터 광장 (서울시 공공데이터)
    • Kaggle (국제 데이터셋 공유 플랫폼)

    개념 4: 프로젝트 문서화 (Documentation)¶

    비유: 과학 실험을 할 때 실험 절차와 결과를 노트에 기록하듯이, 데이터 프로젝트도 어떻게 했는지 기록해야 합니다.

    정의: 문서화란 데이터 수집부터 정제까지의 모든 단계, 결정, 코드를 기록하여 다른 사람(또는 미래의 나)이 이해하고 재현할 수 있게 만드는 과정입니다.

    문서에 포함해야 할 내용:

    • 프로젝트 제목과 목표
    • 데이터 수집 방법과 일시
    • 수집한 데이터의 규모 (몇 개의 행, 몇 개의 컬럼)
    • 정제 과정에서 한 작업들 (어떤 결측값을 어떻게 처리했는지)
    • 최종 결과 (깔끔하게 정제된 CSV 파일)
    • 배운 점과 개선할 점

    • 옵션 A: 구글 설문지로 설문 조사하기
    • 옵션 B: 공공 데이터 다운로드하기
    • 옵션 C: 웹에서 직접 데이터 모으기

    지금부터는 옵션 A (구글 설문지 이용)를 중심으로 설명할게요. 가장 만들기 쉽고 Part 2의 모든 기술을 연습할 수 있거든요!

    Step 1: 주제와 계획 세우기¶

    먼저 여러분이 알고 싶은 것을 정하세요. 너무 복잡할 필요는 없어요. 재미있으면 됩니다! 😊

    주제 아이디어:

    • 우리 반 학생들의 취미 (또는 좋아하는 음식, 관심사)
    • 친구들의 수면 시간과 학습 시간의 관계
    • 가족 구성원들의 영화 장르 선호도
    • 학교 근처 카페들의 메뉴와 가격

    주제를 정했으면 다음을 정리하세요:

    📋 나의 프로젝트 계획서

제목: _________________________________
목표: _________________________________
대상: 약 몇 명에게 물어볼 것인가? ______명
수집 항목: 어떤 정보를 모을 것인가?
  - 항목 1: __________________________
  - 항목 2: __________________________
  - 항목 3: __________________________

    예시: 우리 반 학생들의 공부 습관 조사

    제목: 우리 반 30명의 공부 습관 분석
목표: 학생들의 공부 방식과 선호하는 과목 파악
대상: 약 30명
수집 항목:
  - 이름
  - 선호하는 과목 (국어, 수학, 영어, 과학)
  - 하루 공부 시간 (1시간 미만, 1-2시간, 2시간 이상)
  - 주로 공부하는 장소 (집, 학교, 카페, 도서관)

    Step 2: 구글 설문지로 설문 만들기¶

    지금부터는 구글 설문지(Google Forms)를 사용합니다. 무료이고 쉬워요!

    1. Google Forms 접속
    2. 웹 브라우저에서 forms.google.com에 접속
    3. Google 계정으로 로그인 (gmail 주소로 로그인하면 됩니다)

    4. "새로운 설문지 시작" → 빈 설문지 선택

    5. 설문지 제목과 설명 작성

    6. "설문 제목" 칸에 프로젝트 제목 입력 (예: "우리 반 공부 습관 조사")

    7. "설명" 칸에 간단한 목적 입력 (예: "학생들의 공부 방식을 알아보기 위한 조사입니다")

    8. 질문 추가하기

    9. "+" 버튼을 클릭해서 질문을 하나씩 추가
    10. 질문 유형 선택:
      • "단답형": 짧은 답변 (이름, 번호 등)
      • "객관식": 보기 중 하나만 선택 (과목 선택 등)
      • "체크박스": 여러 개 선택 가능

    예시 질문들: 

    Q1. 이름을 입력하세요 (단답형)
Q2. 선호하는 과목을 선택하세요 
    - 국어  - 수학  - 영어  - 과학 (객관식)
Q3. 하루 공부 시간은? 
    - 1시간 미만  - 1-2시간  - 2시간 이상 (객관식)
Q4. 주로 공부하는 장소는? (체크박스)
    - 집  - 학교  - 카페  - 도서관

    1. 설문지 공유
    2. 설정 아이콘 → "응답" 탭 → "응답 수집 설정"에서 필요한 옵션 선택
    3. 설문지 링크 복사 후 친구들에게 공유 (카톡, 이메일 등)
    4. 최소 10-30명의 응답을 목표로!

    ✅ 체크포인트: 설문지가 공유되었다면 친구들에게 링크를 보내고 응답을 받아보세요! 처음엔 적어도 3-5명의 응답이 들어올 때까지 기다려주세요.

    Step 3: 응답 데이터를 CSV 파일로 내보내기¶

    설문 응답이 충분히 들어오면 (최소 10명 이상), 데이터를 다운로드합니다.

    1. Google Forms에서 응답 보기

    Step 5: 데이터 정제하기¶

    Step 5-1: 불필요한 컬럼 제거

    Google Forms의 첫 번째 컬럼인 "Timestamp" (응답 시간)는 분석에 필요 없을 수 있으니 제거합니다:

    # Timestamp 컬럼 제거
df = df.drop('Timestamp', axis=1)

print("컬럼명:", df.columns.tolist())  # 남은 컬럼 확인

    Step 5-2: 컬럼명 정리

    Google Forms에서는 한글 컬럼명이 길 수 있으니 짧게 정리합니다:

    # 컬럼명 바꾸기 (딕셔너리 사용)
df.rename(columns={
    '이름': 'name',
    '선호 과목': 'subject',
    '공부시간': 'study_time',
    '공부장소': 'study_place'
}, inplace=True)

print(df.head())

    Step 5-3: 결측값 확인 및 처리

    # 결측값 개수 확인
print("결측값 개수:")
print(df.isnull().sum())

# 결측값이 있는 행 보기
print("\n결측값 있는 행:")
print(df[df.isnull().any(axis=1)])

# 결측값 제거 (행 전체 삭제)
df = df.dropna()
print(f"\n정제 후 데이터 개수: {len(df)}개")

    Step 5-4: 텍스트 정규화 (공백 제거, 소문자 통일)

    # 모든 텍스트 컬럼의 앞뒤 공백 제거
df['name'] = df['name'].str.strip()
df['subject'] = df['subject'].str.strip()
df['study_place'] = df['study_place'].str.strip()

# 대문자를 소문자로 통일 (선택사항)
df['subject'] = df['subject'].str.lower()

print(df.head())

    Step 5-5: 중복값 확인 및 제거

    # 같은 사람이 여러 번 응답한 경우 제거 (이름 기준)
print(f"중복 이름: {df['name'].duplicated().sum()}개")

# 중복값 제거 (첫 응답만 보관)
df = df.drop_duplicates(subset=['name'], keep='first')
print(f"중복 제거 후: {len(df)}개")

    Step 5-6: 정제된 데이터 저장

    # 정제된 데이터를 새 CSV로 저장
df.to_csv('my_survey_data_cleaned.csv', index=False, encoding='utf-8-sig')

print("✅ 정제 완료! 'my_survey_data_cleaned.csv'로 저장되었습니다.")
print("\n최종 데이터:")
print(df.head(10))
print(f"\n총 {len(df)}명의 응답 정리됨")

    ✅ 체크포인트: 여기까지 잘 따라왔다면 깔끔하게 정제된 CSV 파일이 2개 생겨야 합니다: - my_survey_data.csv (원본 데이터) - my_survey_data_cleaned.csv (정제된 데이터)

    📝 전체 코드¶

    한 번에 실행할 수 있는 완전한 정제 코드:

    import pandas as pd

# 1️⃣ 데이터 불러오기
df = pd.read_csv('my_survey_data.csv')
print("=== 원본 데이터 ===")
print(f"형태: {df.shape}")
print(df.head())

# 2️⃣ 불필요한 컬럼 제거
df = df.drop('Timestamp', axis=1)

# 3️⃣ 컬럼명 정리 (원본 컬럼명에 맞게 수정하세요!)
df.rename(columns={
    '이름': 'name',
    '선호 과목': 'subject',
    '공부시간': 'study_time',
    '공부장소': 'study_place'
}, inplace=True)

# 4️⃣ 결측값 제거
print("\n=== 정제 과정 ===")
print(f"정제 전: {len(df)}개")
df = df.dropna()
print(f"결측값 제거 후: {len(df)}개")

# 5️⃣ 텍스트 정규화
for col in ['name', 'subject', 'study_time', 'study_place']:
    if col in df.columns:
        df[col] = df[col].str.strip().str.lower()

# 6️⃣ 중복값 제거
df = df.drop_duplicates(subset=['name'], keep='first')
print(f"중복 제거 후: {len(df)}개")

# 7️⃣ 정제된 데이터 저장
df.to_csv('my_survey_data_cleaned.csv', index=False, encoding='utf-8-sig')

# 8️⃣ 최종 결과 확인
print("\n=== 정제 완료 ===")
print(df.head(10))
print(f"\n✅ 총 {len(df)}명의 데이터가 정리되었습니다!")

    ⚠️ 자주 하는 실수¶

    실수 1: 한글 파일명이나 경로 때문에 파일을 찾지 못하는 경우¶

    왜 이런 일이 생기나요? Python이 한글 경로를 제대로 인식하지 못할 수 있습니다.

    이렇게 해결해요: 

    # ❌ 나쁜 예
df = pd.read_csv('내 설문 데이터.csv')

# ✅ 좋은 예: 영문 파일명 사용
df = pd.read_csv('my_survey_data.csv')

# ✅ 또 다른 방법: 절대 경로 사용
import os
file_path = os.path.join(os.getcwd(), 'my_survey_data.csv')
df = pd.read_csv(file_path)

    실수 2: 원본 데이터를 정제하면서 덮어쓰는 경우¶

    왜 이런 일이 생기나요? 원본 데이터를 실수로 변경하면, 나중에 다시 확인할 수 없습니다.

    이렇게 해결해요: 

    # ❌ 나쁜 예: 원본 덮어쓰기
df.to_csv('my_survey_data.csv', index=False)  # 원본 손상!

# ✅ 좋은 예: 새로운 파일로 저장
df.to_csv('my_survey_data_cleaned.csv', index=False)

    실수 3: 컬럼명이 정확하지 않아서 오류 발생¶

    왜 이런 일이 생기나요? Google Forms에서 다운로드한 실제 컬럼명이 예상과 다를 수 있습니다.

    이렇게 해결해요: 

    # 먼저 실제 컬럼명 확인!
print(df.columns.tolist())

# 그 다음에 rename 실행
# 예: ['Timestamp', 'Your Name', 'Favorite Subject', 'Study Time', 'Study Place']
df.rename(columns={
    'Your Name': 'name',
    'Favorite Subject': 'subject',
    'Study Time': 'study_time',
    'Study Place': 'study_place'
}, inplace=True)

    # 프로젝트 보고서: 우리 반 공부 습관 조사

## 1. 프로젝트 목표
우리 반 학생들의 공부 방식과 선호하는 과목을 파악한다.

## 2. 데이터 수집 방법
- 도구: Google Forms 설문지
- 대상: 우리 반 학생 30명
- 기간: 2024년 1월 15일 ~ 1월 20일
- 수집 항목: 이름, 선호 과목, 하루 공부 시간, 공부장소

## 3. 데이터 정제 과정
- 원본 데이터: 25명 (5명 미응답)
- Timestamp 컬럼 제거
- 컬럼명을 영문으로 정리 (이름 → name)
- 결측값 0개 (모두 필수 항목으로 설정)
- 중복값 0개
- 최종 데이터: 25명

## 4. 주요 발견
- 가장 인기 있는 과목: 영어 (12명)
- 평균 공부 시간: 1-2시간 (16명)
- 가장 많이 공부하는 장소: 집 (20명)

- Google Forms로 간단하게 설문을 만들 수 있다
- 수집한 데이터도 정제 과정이 필요하다
