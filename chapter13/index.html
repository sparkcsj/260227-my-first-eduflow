    13장. 직접 해보는 미니 프로젝트 — 데이터로 이야기 만들기¶

    🎯 이 장의 학습 목표¶

    • 데이터셋을 선택해 파이썬으로 분석하고 시각화할 수 있다
    • 데이터에서 발견한 인사이트를 한 문장으로 표현할 수 있다
    • 예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    • 12장까지 배운 pandas, matplotlib 기본 사용법

    📚 핵심 개념¶

    개념: 데이터 분석의 전체 흐름¶

    데이터 분석은 마치 외국어 지문을 읽고 해석하는 것과 같아요. 지문을 읽고(수집) → 핵심을 파악하고(분석) → 내 말로 요약하는(해석) 과정이죠.

    flowchart LR A["❓ 질문 만들기"] --> B["📥 데이터 불러오기"] B --> C["📊 시각화하기"] C --> D["💡 이야기 쓰기"]

    오늘은 이 흐름을 직접 처음부터 끝까지 해봅니다!

    🔨 따라하기¶

    Step 1: 데이터 준비 & 질문 만들기¶

    아래 코드는 "외국어 공부 시간이 많을수록 성적이 좋을까?" 라는 질문으로 시작합니다.

    import pandas as pd
import matplotlib.pyplot as plt

# 외국어 학습 시간(주당)과 시험 점수 데이터
data = pd.DataFrame({
    'study_hours': [2, 5, 1, 8, 3, 7, 4, 6, 10, 9],
    'score':       [55, 72, 40, 90, 58, 85, 65, 78, 95, 88]
})
print(data)

    실행 결과: 

       study_hours  score
0            2     55
1            5     72
2            1     40
...

    Step 2: 시각화하고 이야기 쓰기¶

    plt.scatter(data['study_hours'], data['score'])
plt.xlabel('Weekly Study Hours')
plt.ylabel('Score')
plt.title('Study Hours vs Score')
plt.show()

    그래프를 보고 한 문장으로 써보세요:

    💡 예시: "주당 학습 시간이 늘어날수록 시험 점수가 높아지는 경향이 있다."

    이것이 바로 데이터가 들려주는 이야기예요! 🎉

    📝 전체 코드¶

    import pandas as pd
import matplotlib.pyplot as plt

data = pd.DataFrame({
    'study_hours': [2, 5, 1, 8, 3, 7, 4, 6, 10, 9],
    'score':       [55, 72, 40, 90, 58, 85, 65, 78, 95, 88]
})

plt.scatter(data['study_hours'], data['score'])
plt.xlabel('Weekly Study Hours')
plt.ylabel('Score')
plt.title('Study Hours vs Score')
plt.show()

# 나의 인사이트 한 문장:
print("학습 시간이 많을수록 점수가 높아지는 경향이 보인다.")

    ⚠️ 주의할 점¶

    • 인사이트는 그래프에서 보이는 것만 쓰세요. "반드시 ~이다"보다 "~하는 경향이 있다"가 정확해요.
    • 데이터가 적으면 결론도 조심스러워야 해요. 이것이 데이터 리터러시입니다.

    ✅ 점검하기¶

    1. 데이터 분석의 4단계를 순서대로 말해보세요.
    정답 확인질문 → 수집(불러오기) → 시각화(분석) → 해석(이야기 쓰기)
    1. scatter 그래프는 어떤 관계를 볼 때 유용한가요?
    정답 확인두 숫자 데이터 사이의 관계(상관관계)를 한눈에 파악할 때 유용합니다.

    🎉 축하해요! 질문부터 해석까지, 데이터 분석의 전체 과정을 직접 해냈어요. 데이터도 하나의 언어입니다. 여러분은 이제 그 언어를 읽을 수 있어요!
