    💡 왜 이걸 배우나요?¶

    날씨가 더워지면 아이스크림 판매량이 늘어나요. 맞죠? 그런데 같은 시간에 익사 사고도 함께 증가한다면?

    "아이스크림이 익사를 유발하는가?"라고 묻는다면 웃을 거예요. 하지만 뉴스나 광고에서는 이런 식의 논리 오류가 자주 일어나요.

    "커피를 마시면 수면 부족이 생긴다" "휴대폰을 많이 보면 눈이 나빠진다" "운동을 하면 건강해진다"

    이런 말들이 항상 맞을까요? 아니면 단순히 함께 변하는 것일까요?

    이 장에서는 데이터에서 "함께 변하는 관계"를 찾아내고, 그것이 "원인-결과 관계"인지 아닌지를 판단하는 방법을 배워요. 이것은 거짓 정보에 속지 않는 중요한 스킬이랍니다! 🎯

    📚 핵심 개념¶

    개념 1: 상관관계란 무엇인가?¶

    비유로 시작해볼게요:

    친한 친구들을 생각해 보세요. 한 친구가 카페에 가면 다른 친구도 함께 가곤 하지 않나요? 둘의 행동이 서로 영향을 주는 건 아니지만, 함께 움직이는 패턴이 있어요. 이것을 "함께 변한다"고 말합니다.

    정확한 정의:

    상관관계는 두 변수가 함께 변하는 정도를 나타내는 통계적 관계예요.

    ⚡ 중요: 상관관계는 "함께 변한다"는 것이지, "원인이 된다"는 뜻이 아니에요!

    상관관계는 세 가지 종류로 나뉩니다:

    양의 상관(Positive Correlation): 한 변수가 증가하면 다른 변수도 증가해요. - 예: 공부 시간 ↑ → 시험 점수 ↑ - 예: 온도 ↑ → 아이스크림 판매량 ↑

    음의 상관(Negative Correlation): 한 변수가 증가하면 다른 변수는 감소해요. - 예: 운동량 ↑ → 체지방률 ↓ - 예: 휴식 시간 ↑ → 피로도 ↓

    무상관(No Correlation): 두 변수 사이에 뚜렷한 관계가 없어요. - 예: 신발 사이즈와 수학 성적 - 예: 생일과 키

    다음 다이어그램으로 세 가지를 한눈에 비교해 봐요:

    graph LR A["🔴 양의 상관\n한쪽↑ → 다른쪽↑"] --> B["⚡ 강한 상관계수"] C["🔵 음의 상관\n한쪽↑ → 다른쪽↓"] --> D["⚡ 강한 상관계수"] E["⚪ 무상관\n한쪽변화 → 다른쪽 무변화"] --> F["⚡ 약한 상관계수"]

    예시로 확인해 볼까요:

    만약 100명의 학생 데이터를 모아서 "공부 시간"과 "시험 점수"를 점으로 표현한다면, 대부분의 점들이 왼쪽 아래에서 오른쪽 위로 향하는 직선 모양이 될 거예요. 이게 양의 상관이에요.

    반대로 "남은 휴식 일수"와 "누적 피로도"를 표현하면, 왼쪽 위에서 오른쪽 아래로 향하는 직선이 될 거예요. 이게 음의 상관이에요.

    개념 2: 상관관계 vs 인과관계¶

    여기가 정말 중요한 부분이에요! 많은 사람들이 헷갈려하거든요.

    상관관계: 두 변수가 함께 변한다. 인과관계: 한 변수가 원인이 되어 다른 변수에 결과를 만든다.

    실제 사례를 봐볼까요:

    🍦 아이스크림과 익사 사고

    • 상관관계 O: 여름(더운 날씨)에 아이스크림 판매량과 익사 사고가 모두 증가해요.
    • 인과관계 O: 실제 원인은 따뜻한 날씨(숨은 변수)예요.
    • 날씨가 따뜻하니까 → 사람들이 아이스크림을 먹고
    • 날씨가 따뜻하니까 → 사람들이 물에 간다 (익사 위험↑)

    결론: 아이스크림이 익사를 유발하는 게 아니에요!

    다음 그림으로 이 관계를 명확히 봐요:

    graph TD Weather["🌞 따뜻한 날씨\n(숨은 변수)"] IceCream["🍦 아이스크림 판매↑"] Drowning["🌊 익사 사고↑"] Weather --> IceCream Weather --> Drowning style Weather fill:#ffeb3b style IceCream fill:#ff6b6b style Drowning fill:#4ecdc4

    상관관계를 찾을 때 꼭 기억해야 할 세 가지:

    1. 숨은 원인(Confounding Variable): 두 변수를 함께 움직이는 제3의 변수
    2. 역의 인과관계: A→B라고 생각했지만 실은 B→A일 수도
    3. 우연의 일치: 정말로 아무 관련이 없는데 우연히 함께 변한 것

    💡 핵심 규칙: "상관관계가 있다 ≠ 인과관계가 있다"

    개념 3: 상관계수로 수치화하기¶

    상관관계가 얼마나 강한지 숫자로 나타낼 수 있어요. 이걸 상관계수라고 불러요.

    가장 많이 사용하는 방법: 피어슨 상관계수(Pearson Correlation Coefficient)

    값의 범위: -1 ~ +1

    • +1에 가까울수록: 아주 강한 양의 상관
    • 0에 가까울수록: 상관이 약함 (무상관)
    • -1에 가까울수록: 아주 강한 음의 상관

    직관적으로 이해해 보세요:

    +1.0  ━━━ 완벽한 양의 상관 (100% 함께 증가)
+0.7  ━━◐ 강한 양의 상관
+0.3  ━◐  보통 양의 상관
 0.0  ◐   상관 없음
-0.3  ◑━  보통 음의 상관
-0.7  ◑━━ 강한 음의 상관
-1.0  ◑━━ 완벽한 음의 상관 (100% 반대로 변함)

    예를 들어: - 공부 시간과 시험 성적: r = 0.8 (강한 양의 상관) - 신발 사이즈와 수학 성적: r = 0.05 (무상관) - 운동량과 체지방: r = -0.75 (강한 음의 상관)

    개념 4: 점그래프(Scatter Plot)로 관계 보기¶

    상관관계를 눈으로 직접 확인하는 가장 좋은 방법이에요!

    점그래프는 간단해요: - 가로축(X): 첫 번째 변수 - 세로축(Y): 두 번째 변수 - 각 점: 하나의 관측치(사람, 물건, 날짜 등)

    세 가지 패턴을 봐요:

    graph LR subgraph Positive["양의 상관"] A["📈 왼쪽 아래 → 오른쪽 위로"] end subgraph Negative["음의 상관"] B["📉 왼쪽 위 → 오른쪽 아래로"] end subgraph None["무상관"] C["⚪ 점들이 흩어짐"] end

    💡 팁: 점그래프에서 직선 모양이 보일수록 상관이 강한 거예요!

    🔧 따라하기¶

    Step 1: 오렌지3에서 샘플 데이터 불러오기¶

    먼저 오렌지3를 열고, 학생 성적 데이터를 준비할 거예요.

    하기: 1. 오렌지3를 켜세요 2. 왼쪽 패널에서 Data → File 위젯을 드래그해서 캔버스에 놓세요 3. 위젯을 더블클릭해서 파일 창을 열어요 4. 내 컴퓨터에 있는 CSV 파일을 선택하거나, 오렌지3 샘플 데이터 중 "iris.csv" 또는 "housing.csv"를 선택하세요

    ✅ 체크포인트: 파일이 열리고 데이터 미리보기가 보이면 성공!

    Step 2: Scatter Plot 위젯 연결하기¶

    이제 점그래프를 만들 거예요.

    하기: 1. Visualize → Scatter Plot 위젯을 캔버스에 놓으세요 2. File 위젯과 Scatter Plot을 마우스로 드래그해서 연결해요 - File 위젯의 출력 포트 → Scatter Plot 위젯의 입력 포트 3. 연결이 완료되면 Scatter Plot에 데이터가 자동으로 로드돼요

    ✅ 체크포인트: Scatter Plot 위젯이 흰 화면에서 점들이 표시되도록 변해야 해요

    Step 3: 두 변수를 선택해 상관관계 탐색하기¶

    Scatter Plot에서 보고 싶은 두 변수를 선택해요.

    하기: 1. Scatter Plot 위젯을 더블클릭해서 설정 창을 열어요 2. X축(가로)에 올 변수 선택 (예: "꽃받침 길이") 3. Y축(세로에 올 변수) 선택 (예: "꽃잎 길이") 4. 변수를 선택하면 즉시 점그래프가 업데이트돼요

    여러 쌍을 시도해 보세요: - 꽃받침 길이 vs 꽃받침 너비 (양의 상관일까?) - 꽃받침 길이 vs 꽃잎 길이 (양의 상관일까?)

    💡 팁: 점들이 직선에 가까울수록 상관이 강해요. 흩어져 있을수록 약해요!

    Step 4: 파이썬으로 상관계수 계산하기¶

    이제 수치로도 확인해 봐요. 간단한 파이썬 코드면 충분합니다.

    import pandas as pd

# 데이터 불러오기 (iris.csv 기준)
df = pd.read_csv('iris.csv')

# 상관계수 계산 (전체 변수 간)
print(df.corr())

# 특정 두 변수만 계산
r = df['꽃받침 길이'].corr(df['꽃잎 길이'])
print(f"꽃받침 길이와 꽃잎 길이의 상관계수: {r:.3f}")

    실행 결과 해석: - r = 0.87 → "꽃받침이 길수록 꽃잎도 길다" (강한 양의 상관) - r = 0.02 → "거의 관계가 없다" (무상관) - r = -0.43 → "한쪽이 길수록 다른 쪽은 짧다" (음의 상관)

    ✅ 체크포인트: 상관계수가 -1 ~ +1 사이의 수로 나와야 해요

    Step 5: 색칠해서 더 명확하게 보기¶

    오렌지3에서는 점들을 색으로 구분할 수 있어요. 이렇게 하면 패턴이 더 잘 보입니다.

    하기: 1. Scatter Plot 설정 창에서 "색상(Color)" 옵션을 찾아요 2. 꽃의 품종(Species) 같은 범주형 변수를 선택하면 각 그룹이 다른 색으로 표시돼요 3. 각 색 그룹별로 상관 패턴이 다른지 관찰해 보세요

    이렇게 하면 "품종별로 상관관계가 다를 수도 있다"는 중요한 통찰을 얻을 수 있어요!

    Step 6: 직접 만든 데이터로 시도해보기¶

    이번엔 스스로 데이터를 만들어 상관관계를 탐색해 봐요.

    import pandas as pd
import numpy as np

# 양의 상관 데이터 만들기
np.random.seed(42)
hours = np.random.uniform(0, 10, 50)  # 공부 시간 (0~10시간)
scores = hours * 8 + np.random.normal(0, 5, 50)  # 시험 점수 (점수 = 시간*8 + 잡음)

df_study = pd.DataFrame({
    '공부시간': hours,
    '시험점수': scores
})

# CSV로 저장
df_study.to_csv('study_data.csv', index=False)

# 상관계수 확인
r = df_study['공부시간'].corr(df_study['시험점수'])
print(f"상관계수: {r:.3f}")  # 약 0.95 (강한 양의 상관!)

    이 CSV를 오렌지3에서 불러와서 Scatter Plot으로 확인하면, 명확한 양의 상관 직선이 보일 거예요!

    💡 깨달음: 우리가 직접 "시간이 길수록 점수가 높다"라는 관계를 만들었으니, 이건 명백한 인과관계랍니다!

    📝 전체 코드¶

    상관관계 완벽 분석 스크립트:

    import pandas as pd
import matplotlib.pyplot as plt

# 1. 데이터 불러오기
df = pd.read_csv('iris.csv')

# 2. 전체 상관계수 매트릭스 출력
print("=" * 50)
print("전체 변수 간 상관계수")
print("=" * 50)
print(df.corr().round(3))

# 3. 특정 변수 쌍의 상관계수
print("\n" + "=" * 50)
print("주요 쌍별 상관계수")
print("=" * 50)
variable_pairs = [
    ('꽃받침 길이', '꽃받침 너비'),
    ('꽃받침 길이', '꽃잎 길이'),
    ('꽃잎 길이', '꽃잎 너비')
]

for var1, var2 in variable_pairs:
    r = df[var1].corr(df[var2])
    interpretation = "강한 양의 상관" if r > 0.7 else "보통 양의 상관" if r > 0.3 else "약한 상관" if r > 0 else "음의 상관"
    print(f"{var1} ↔ {var2}: {r:.3f} ({interpretation})")

# 4. 점그래프로 시각화 (matplotlib 사용)
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

axes[0].scatter(df['꽃받침 길이'], df['꽃받침 너비'], alpha=0.6)
axes[0].set_xlabel('꽃받침 길이')
axes[0].set_ylabel('꽃받침 너비')
axes[0].set_title('약한 양의 상관')

axes[1].scatter(df['꽃받침 길이'], df['꽃잎 길이'], alpha=0.6, color='orange')
axes[1].set_xlabel('꽃받침 길이')
axes[1].set_ylabel('꽃잎 길이')
axes[1].set_title('강한 양의 상관')

axes[2].scatter(df['꽃잎 길이'], df['꽃잎 너비'], alpha=0.6, color='green')
axes[2].set_xlabel('꽃잎 길이')
axes[2].set_ylabel('꽃잎 너비')
axes[2].set_title('강한 양의 상관')

plt.tight_layout()
plt.show()

# 5. 상관관계가 없는 데이터와 비교
df['무의미한변수'] = [i % 3 for i in range(len(df))]  # 완전히 무작위
r_meaningless = df['꽃받침 길이'].corr(df['무의미한변수'])
print(f"\n꽃받침 길이와 무의미한 변수: {r_meaningless:.3f} (상관 없음!)")

    ⚠️ 자주 하는 실수¶

    실수 1: "상관계수가 높으면 인과관계가 있다"고 생각하기¶

    왜 이런 일이 생기나요? 상관계수 0.9는 정말 강한 관계를 의미해요. 그래서 "뭔가 원인-결과가 있을 것 같은" 착각이 들 수 있어요.

    이렇게 해결해요: - 상관계수가 높아도, 다른 변수의 영향이 있을 수 있어요 - "왜 함께 변할까?"라는 의문을 항상 던져 보세요 - 실험으로 인과관계를 확인해야 해요 (단순 데이터 분석으로는 불가능)

    💡 기억할 문장: "상관은 인과를 증명하지 않는다"

    실수 2: 샘플이 적을 때 상관계수 신뢰하기¶

    왜 이런 일이 생기나요? 데이터가 5개, 10개 정도면 우연히 높은 상관계수가 나올 수 있어요.

    이렇게 해결해요: - 최소한 30개 이상의 데이터를 모아야 신뢰할 수 있어요 - 작은 샘플은 점그래프에서 뚜렷한 직선 패턴이 없을 가능성이 높아요 - "p-value"라는 통계량으로 통계적 유의성을 확인하세요 (이건 더 고급 과정)

    실수 3: 이상치(Outlier)를 무시하기¶

    왜 이런 일이 생기나요? 한 두 개의 매우 다른 값이 있으면 상관계수가 크게 달라질 수 있어요.

    이렇게 해결해요: - 점그래프를 항상 눈으로 먼저 확인해 보세요 - 점들로부터 멀리 떨어진 점이 있다면 왜 그런지 조사해 봐요 - 필요하면 그 점을 제거하고 다시 계산해 봐요

    예시: 

    # 이상치 확인
import numpy as np
Q1 = df['꽃받침 길이'].quantile(0.25)
Q3 = df['꽃받침 길이'].quantile(0.75)
IQR = Q3 - Q1

# Q1-1.5*IQR ~ Q3+1.5*IQR 범위 밖의 값은 이상치
outliers = df[(df['꽃받침 길이'] < Q1 - 1.5*IQR) | (df['꽃받침 길이'] > Q3 + 1.5*IQR)]
print(f"발견된 이상치: {len(outliers)}개")
