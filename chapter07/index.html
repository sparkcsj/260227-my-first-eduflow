    Chapter 07. 처음 만나는 파이썬 — 영어처럼 읽히는 코드¶

    🎯 이 장의 학습 목표¶

    • Google Colab에서 파이썬 첫 코드를 실행할 수 있다
    • 변수의 개념을 이해하고 활용할 수 있다
    • print 함수로 데이터를 화면에 출력할 수 있다
    • 파이썬 코드를 영어 문장처럼 읽을 수 있다

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    이전 장에서는 데이터 수집의 중요성과 기본 개념을 배웠어요. 이제 파이썬이라는 도구를 사용해서 직접 데이터를 다루어봅시다. 프로그래밍 경험이 전혀 없어도 괜찮습니다!

    💡 왜 이걸 배우나요?¶

    외고에서 영어를 배운 여러분은 이미 큰 장점이 있어요. 파이썬은 세상에서 가장 영어에 가까운 프로그래밍 언어거든요.

    예를 들어볼까요?

    영어: "If you are a student, print your name"
파이썬: if you_are_student: print(your_name)

    파이썬의 if, for, print 같은 키워드는 모두 우리가 아는 영어 단어예요. 게다가 데이터 분석을 하려면 파이썬이 필수 도구랍니다. 금융, 마케팅, 통계, 인공지능 분야에서는 거의 모두 파이썬을 사용해요.

    이 장을 마치면, 여러분은 파이썬으로 간단한 데이터를 저장하고 출력할 수 있게 돼요. 어렵지 않습니다. 천천히 시작해봅시다!

    📚 핵심 개념¶

    개념 1: 프로그래밍이란 '컴퓨터에게 명령하기'¶

    비유로 시작: 파이썬으로 코드를 쓰는 것은 컴퓨터라는 로봇에게 명령을 적어주는 것과 같아요. 로봇이 우리 말을 정확히 알아듣도록 특정한 문법을 써야 하는데, 다행히 파이썬의 문법은 매우 간단해요.

    정확한 정의: 프로그래밍은 프로그래밍 언어를 사용해서 컴퓨터가 수행할 일련의 명령어들을 작성하는 행위입니다. 파이썬은 이러한 명령어를 영어처럼 자연스럽게 쓸 수 있도록 설계된 언어예요.

    예시로 확인:

    print("안녕하세요!")

    이 한 줄은 "화면에 '안녕하세요!'라고 출력해줘"라는 명령이에요. print는 "출력하다"라는 뜻의 영어 단어죠.

    개념 2: 변수 — '이름표'로 데이터를 관리하기¶

    비유로 시작: 학교 교실을 생각해보세요. 모든 학생에게 자기 자리가 있죠? 파이썬의 변수도 마찬가지예요. 데이터를 보관할 상자에 이름을 붙여서 관리하는 거예요.

    name = "김민준"

    이것은 "name이라는 상자에 '김민준'을 보관해줘"라는 뜻이에요.

    정확한 정의: 변수(variable)는 데이터를 저장하는 메모리 공간을 가리키는 이름입니다. = 기호를 사용해서 변수에 값을 할당(저장)합니다.

    예시로 확인:

    school = "대전외고"
year = 2026
gpa = 4.1
    • school이라는 상자에 "대전외고"를 저장
    • year이라는 상자에 2026을 저장
    • gpa이라는 상자에 4.1을 저장

    💡 팁: 변수 이름은 소문자로, 여러 단어를 쓸 때는 my_school 처럼 언더스코어(_)로 연결해요!

    개념 3: 자료형 — 데이터의 '종류'¶

    비유로 시작: 편의점에 가면 음료수, 과자, 생활용품이 다른 코너에 놓여있죠? 파이썬도 데이터의 종류(자료형)에 따라 다르게 취급해요.

    정확한 정의: 자료형(data type)은 데이터의 종류를 나타내는 개념입니다. 파이썬에서 가장 중요한 자료형은 3가지예요.

    # 1. 문자열(String) — 따옴표로 감싼 텍스트
name = "이지은"
city = '대전'

# 2. 정수(Integer) — 소수가 없는 숫자
year = 2026
score = 95

# 3. 실수(Float) — 소수가 있는 숫자
height = 165.7
average = 4.15

    ⚠️ 중요: 문자열은 반드시 따옴표(" 또는 ')로 감싸야 해요. "100"과 100은 전혀 다른 데이터예요!

    개념 4: print 함수 — 데이터를 화면에 보여주기¶

    비유로 시작: 변수에 데이터를 저장하는 것은 상자에 물건을 넣는 것 같고, print는 그 상자를 열어서 내용을 확인하는 거예요.

    정확한 정의: print()는 함수(function)로, 괄호 안의 데이터를 화면에 출력해주는 역할을 해요. 함수는 "특정한 작업을 수행하는 도구"라고 생각하면 돼요.

    예시로 확인:

    print("Hello, Data!")
print(2026)
print(4.15)

    💡 아이디어: print() 함수를 사용할 때는 괄호를 꼭 붙여야 해요. 잊으면 오류가 나요!

    🔧 직접 해봐요¶

    Step 1: Google Colab 접속하기¶

    목표: 파이썬을 실행할 수 있는 환경을 준비합니다.

    따라하기:

    1. 웹 브라우저를 열고 colab.research.google.com에 접속해요
    2. Google 계정으로 로그인하면 자동으로 파이썬 환경이 준비돼요
    3. "+ 새 노트북" 버튼을 클릭해요
    4. 화면에 작은 칸(셀)이 나타나면 준비 완료!

    ✅ 체크포인트: 빈 코드 입력 칸이 보이나요? 그럼 다음 단계로 가요!

    Step 2: 첫 번째 명령 실행하기¶

    목표: 파이썬에게 첫 번째 명령을 내립니다.

    따라하기:

    1. Google Colab의 빈 칸에 다음을 입력하세요:
    print("Hello, Data!")
    1. 키보드에서 Ctrl + Enter를 눌러요 (맥은 Cmd + Enter)
    2. 화면 아래에 Hello, Data!가 나타나면 성공!

    ✅ 체크포인트: "Hello, Data!"라는 글자가 출력되었나요? 축하합니다! 여러분은 지금 프로그래머예요! 🎉

    Step 3: 변수 만들고 출력하기¶

    목표: 변수를 만들어서 데이터를 저장하고 출력합니다.

    따라하기:

    1. 새 칸을 만들어요 (Ctrl + M)
    2. 다음 코드를 입력하세요:
    school = "대전외고"
grade = 2026
print(school)
print(grade)
    1. Ctrl + Enter를 눌러요
    2. 화면에 다음이 출력되면 성공: 
      대전외고
2026

    ✅ 체크포인트: 변수에 저장한 데이터가 화면에 보이나요? 변수가 정확히 작동한다는 증거예요!

    Step 4: 여러 데이터를 한 줄에 출력하기¶

    목표: 한 번에 여러 개의 데이터를 보여줍니다.

    따라하기:

    1. 새 칸에 다음을 입력하세요:
    print("학교:", school)
print("예상 졸업년도:", grade)
    1. Ctrl + Enter를 눌러요
    2. 결과: 
      학교: 대전외고
예상 졸업년도: 2026

    이런 식으로 문장처럼 데이터를 섞어서 출력할 수 있어요!

    Step 5: 자료형 실습하기¶

    목표: 다양한 자료형의 데이터를 직접 다뤄봅니다.

    따라하기:

    1. 새 칸에 입력하세요:
    # 학생 정보 저장
name = "박지영"           # 문자열
school_year = 2026         # 정수
gpa = 4.25                #실수
is_class_president = True  # True/False (불린형)

# 모든 정보 출력
print(name)
print(school_year)
print(gpa)
print(is_class_president)
    1. Ctrl + Enter를 눌러요
    2. 각 데이터가 저장된 순서대로 출력돼요

    ✅ 체크포인트: 문자, 숫자, True/False가 모두 정상 출력되었나요? 축하해요! 기본을 완전히 마스터했어요!

    Step 6: 파이썬을 영어처럼 읽어보기¶

    목표: 코드를 소리 내어 읽으면서 그 의미를 파악합니다.

    따라하기:

    다음 코드를 영어처럼 천천히 읽어보세요:

    school = "대전외고"
if school == "대전외고":
    print("대전외고 학생이군요!")

    읽어보기: - Line 1: "변수 school에 '대전외고'를 할당한다" - Line 2: "만약(if) school이 '대전외고'와 같으면(==)" - Line 3: "화면에 '대전외고 학생이군요!'를 출력한다(print)"

    💡 깨달음: 보셨나요? 파이썬 문법이 정말 영어처럼 읽혀요! if, print, == 모두 우리가 아는 영어 단어 또는 기호예요!

    📝 전체 코드 (따라하기를 한 번에 보기)¶

    # 1단계: 첫 번째 명령
print("Hello, Data!")

# 3단계: 변수 만들고 출력
school = "대전외고"
grade = 2026
print(school)
print(grade)

# 4단계: 여러 데이터 한 줄에 출력
print("학교:", school)
print("예상 졸업년도:", grade)

# 5단계: 다양한 자료형
name = "박지영"
school_year = 2026
gpa = 4.25
is_class_president = True

print(name)
print(school_year)
print(gpa)
print(is_class_president)

# 6단계: 조건문과 함께 읽기
school = "대전외고"
if school == "대전외고":
    print("대전외고 학생이군요!")

    이 코드를 Google Colab의 한 칸에 모두 붙여넣고 실행하면 모든 출력을 볼 수 있어요!

    ⚠️ 자주 하는 실수¶

    실수 1: 따옴표를 빼먹기¶

    잘못된 코드: 

    print(Hello, Data!)  # 오류!

    왜 이런 일이 생기나요?
    파이썬은 따옴표가 없으면 Hello를 변수 이름으로 생각해요. 하지만 그런 변수가 없으니까 오류가 나요.

    이렇게 해결해요: 

    print("Hello, Data!")  # 올바른 코드

    팁: 문자열은 항상 따옴표로 감싸세요!

    실수 2: 변수 이름을 정의하지 않고 사용하기¶

    잘못된 코드: 

    print(my_age)  # 오류! my_age를 정의하지 않았어요

    왜 이런 일이 생기나요?
    변수를 사용하려면 먼저 그 변수에 값을 할당해야 해요. 상자를 만들어야 물건을 넣을 수 있는 것처럼요.

    이렇게 해결해요: 

    my_age = 17  # 먼저 변수 정의
print(my_age)  # 이제 사용 가능

    실수 3: 괄호를 빼먹기¶

    잘못된 코드: 

    print "Hello"  # 오류! print 뒤에 괄호가 없어요

    왜 이런 일이 생기나요?
    print는 함수이고, 함수는 반드시 괄호와 함께 사용해야 해요.

    이렇게 해결해요: 

    print("Hello")  # 괄호 필수!

    실수 4: 변수 이름에 공백이나 특수문자 사용하기¶

    잘못된 코드: 

    my school = "대전외고"  # 공백이 있어서 오류!
my-age = 17  # 하이픈도 오류!

    왜 이런 일이 생기나요?
    파이썬의 변수 이름은 알파벳, 숫자, 언더스코어(_)만 사용할 수 있어요.

    이렇게 해결해요: 

    my_school = "대전외고"  # 언더스코어 사용
my_age = 17  # 또는 camelCase: myAge
