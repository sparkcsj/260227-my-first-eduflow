    Chapter 06. 데이터는 어디서 올까 — 수집의 세계¶

    🎯 이 장의 학습 목표¶

    • 데이터 수집의 4가지 주요 방법을 구분하고 각각의 특징을 설명할 수 있어요
    • 1차 데이터와 2차 데이터의 차이를 이해하고 상황에 맞게 선택할 수 있어요
    • 공공데이터포털에서 실제로 원하는 데이터를 검색하고 다운로드할 수 있어요
    • 데이터 수집할 때 지켜야 할 윤리 원칙을 알 수 있어요

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    지난 장에서 데이터가 숫자, 텍스트, 이미지 등 다양한 형태로 존재한다는 걸 배웠어요. 이 장에서는 "이 모든 데이터를 어떻게 모으는가?" 라는 질문에 대답해봅니다. 데이터 분석의 첫 번째 단계니까 제일 중요하다고 할 수 있어요!

    💡 왜 이걸 배우나요?¶

    기자가 좋은 기사를 쓰려면 먼저 취재를 잘해야 하듯이, 데이터 과학자도 좋은 분석을 하려면 먼저 데이터를 잘 모아야 합니다.

    현실에서 만나는 문제들을 생각해 봐요: - 🏪 편의점 사장님: "우리 지점의 고객층이 정확히 누구일까?" - 📱 게임 회사: "새로운 게임이 어떤 연령대에서 인기일까?" - 🌡️ 환경청: "우리 지역의 미세먼지가 정말 많이 났을까?"

    이 모든 질문에 답하려면 첫 번째 할 일이 바로 "데이터를 수집하는 것" 입니다.

    💡 여기서 중요한 진실: 아무리 훌륭한 분석 기술도 나쁜 데이터로는 쓸모없어요. 쓰레기 데이터가 들어오면 쓰레기 결과가 나온다는 "Garbage In, Garbage Out(GIGO)"이 바로 이것이에요!

    📚 핵심 개념¶

    개념 1️⃣: 데이터 수집의 4가지 방법¶

    우리 주변에 데이터는 넘쳐흐르고 있어요. 그런데 어떤 방식으로 모으느냐에 따라 특징과 장단점이 완전히 달라집니다.

    🎯 설문조사 (Survey)¶

    누군가에게 직접 물어보는 방식입니다.

    예시: "좋아하는 음식이 뭐예요?" "휴대폰을 몇 시간 사용하나요?"

    특징: - ✅ 원하는 정보를 직접 정할 수 있어요 (예: 정확히 나이, 직업, 취향) - ✅ 설명을 추가하면 응답자가 이해하고 답할 수 있어요 - ❌ 시간이 오래 걸리고 비용이 많이 들어요 - ❌ 응답자가 거짓말할 수도 있어요

    👁️ 관찰/센서 (Observation & Sensors)¶

    눈으로 보거나, 기계가 자동으로 측정하는 방식입니다.

    예시: CCTV로 카페에 방문한 사람 수 세기, 스마트폰의 GPS로 위치 기록하기, 온도계로 날씨 기록하기

    특징: - ✅ 사람이 거짓말하지 않으니 신뢰도가 높아요 - ✅ 자동으로 계속 수집되므로 대량의 데이터를 모을 수 있어요 - ❌ 원하지 않는 정보까지 함께 모여요 - ❌ 프라이버시 침해 위험이 있어요

    🌐 웹 크롤링 (Web Crawling)¶

    인터넷에 공개된 정보를 프로그램으로 자동 수집하는 방식입니다.

    예시: 쇼핑몰 상품 가격 모으기, 영화 평점 수집, 뉴스 기사 자동 다운로드

    특징: - ✅ 빠르고 비용이 적어요 - ✅ 이미 정리된 공개 데이터를 모을 수 있어요 - ❌ 웹사이트 구조가 바뀌면 못 모을 수도 있어요 - ❌ 법적·윤리적 문제가 생길 수 있어요 (저작권, 이용약관 위반)

    📊 공공 데이터 (Open Data)¶

    정부나 공공기관이 공식적으로 공개한 데이터입니다.

    예시: 대한민국 인구통계, 미세먼지 측정값, 버스·지하철 운행 정보, 범죄 발생 현황

    특징: - ✅ 이미 정리되어 있어서 바로 사용할 수 있어요 - ✅ 신뢰도가 높고 법적으로 안전해요 - ✅ 무료로 다운로드할 수 있어요 - ❌ 원하는 형태가 아닐 수도 있어요 - ❌ 최신 데이터가 아닐 수도 있어요

    개념 2️⃣: 1차 데이터 vs 2차 데이터¶

    이 개념은 데이터가 "누가 만들었는가?" 에 따라 분류해요.

    1차 데이터 (Primary Data)¶

    "내가" 또는 "원래 수집한 사람이" 처음 모은 데이터입니다.

    예시: - 당신이 직접 설문지를 만들어서 100명에게 물어본 결과 - 과학 실험에서 당신이 직접 측정한 온도값 - 당신이 직접 센서를 설치하고 기록한 데이터

    장점: 정확히 필요한 형태로 수집할 수 있어요 단점: 시간과 비용이 많이 들어요

    2차 데이터 (Secondary Data)¶

    "다른 누군가가" 만든 데이터를 나중에 다시 사용하는 것입니다.

    예시: - 통계청에서 공개한 국가통계를 내 분석에 사용 - 온라인 도서관에서 받은 다른 연구자의 데이터 - 인터넷에서 찾은 이미 정리된 데이터셋

    장점: 빨리 구할 수 있고, 큰 규모 데이터를 얻을 수 있어요 단점: 원하는 형태가 아닐 수도 있어요, 최신이 아닐 수도 있어요

    💡 잠깐! 대부분의 실무 데이터 분석은 2차 데이터로 시작해요. 왜냐하면 처음부터 1차 데이터를 모으려면 너무 오래 걸리거든요. 그래서 이번 장에서 공공데이터포털을 배우는 거랍니다!

    개념 3️⃣: 공공데이터포털 (data.go.kr)¶

    한국 정부에서 "국민을 위해 데이터를 공개하겠다"고 결정했어요. 그 결과 만들어진 곳이 공공데이터포털입니다.

    어떤 데이터가 있을까요? - 📊 인구통계, 경제통계, 고용통계 - 🏥 감염병 정보, 의료기관 현황 - 🌡️ 날씨, 미세먼지, 강수량 - 🚗 교통사고, 버스 노선, 지하철 운행 - 🏠 부동산 거래, 아파트 가격 - 🎓 학교 정보, 급식 정보 - 🍽️ 맛집, 관광지 정보

    가장 큰 장점: 완전히 무료이고, 다운로드만 하면 바로 쓸 수 있어요!

    개념 4️⃣: 데이터 수집의 윤리와 법칙¶

    "데이터를 마음대로 수집해도 될까요?" 라는 질문에 답하자면: "아니요, 꼭 지켜야 할 규칙이 있어요!"

    🔒 개인정보 보호 - 누군가의 이름, 주민등록번호, 연락처를 무단으로 모으면 안 돼요 - 법 위반이 될 수 있어요 (개인정보보호법)

    📜 저작권 존중 - 누군가가 만들고 정리한 데이터를 함부로 쓰면 안 돼요 - 출처를 반드시 표시해야 해요

    ⚖️ 이용약관 확인 - 웹사이트 데이터를 크롤링할 때 그 사이트의 이용약관을 읽어야 해요 - "자동 수집 금지"라고 써있으면 크롤링하면 안 돼요

    📢 투명성과 공정성 - 데이터 수집 목적을 명확히 해야 해요 - "이 데이터를 뭐에 쓸 건지" 사람들에게 알려줘야 해요

    ⚠️ 중요: 공공데이터포털의 데이터는 이미 개인정보 처리 승인을 받은 것들이니까 안전하게 써도 좋아요!

    🔨 따라하기¶

    자, 이제 실제로 공공데이터포털에 가서 데이터를 다운로드해 봅시다! 가장 간단하고 실용적인 방법이니까 따라가세요.

    Step 1️⃣: 공공데이터포털 접속하기¶

    목표: 공공데이터포털 웹사이트에 도착하기

    따라하기: 1. 인터넷 브라우저(크롬, 엣지 등)를 열어요 2. 주소창에 data.go.kr 을 입력하고 엔터를 누르세요 3. 한국 정부에서 만든 공식 포털이 뜰 거예요

    ✅ 체크포인트: 가운데에 큰 검색창과 "인기 데이터" 섹션이 보이나요? 그럼 맞게 왔어요!

    Step 2️⃣: 원하는 데이터 검색하기¶

    목표: 관심 있는 주제의 데이터 찾기

    예시 주제들 (이 중 하나를 선택하세요): - "미세먼지" → 대기오염 데이터 - "학교 정보" → 전국 학교 데이터 - "맛집" → 지역 음식점 정보 - "버스" → 버스 노선 및 운행 정보 - "범죄" → 지역별 범죄 발생 현황

    따라하기: 1. 포털의 검색창을 클릭해요 2. 원하는 주제를 입력하세요 (예: "미세먼지") 3. 엔터를 누르거나 검색 버튼을 클릭하세요 4. 검색 결과 목록이 나타나요

    💡 팁: 처음엔 이미 다운로드 수가 많은 데이터로 시작하는 게 좋아요. 왼쪽에서 "인기순"으로 정렬하면 사용하기 좋은 데이터들이 위에 뜹니다!

    Step 3️⃣: 데이터 세트 자세히 보기¶

    목표: 마음에 드는 데이터셋을 선택하고 정보 확인하기

    따라하기: 1. 검색 결과 중 하나를 클릭해요 (제목을 누르면 돼요) 2. 상세 페이지가 열려요. 다음 정보들을 확인하세요: - 📋 데이터 설명: "이 데이터가 뭔가요?" - 📅 업데이트 주기: "언제마다 새로 올려져요?" - 📊 파일 형식: CSV, Excel, JSON 등 - 📦 파일 크기: 얼마나 클까요?

    💡 처음 해볼 때는 파일 크기가 1MB 이하인 것으로 시작하세요. 너무 크면 처음에 다루기 어려워요!

    Step 4️⃣: 파일 다운로드하기¶

    목표: 데이터를 컴퓨터에 저장하기

    따라하기: 1. 상세 페이지에서 아래로 스크롤하세요 2. "파일 정보" 또는 "다운로드" 섹션을 찾아요 3. 파일 형식 중 "CSV" 형식을 선택해요 (가장 다루기 쉬워요!) 4. "다운로드" 버튼을 클릭하세요 5. "저장" 또는 "이 파일을 저장하시겠습니까?" 라고 물어보면 "저장"을 누르세요 6. 컴퓨터의 "다운로드" 폴더에 저장돼요

    ✅ 체크포인트: 다운로드 폴더를 열어서 .csv 파일이 생겼나요? 성공이에요!

    Step 5️⃣: 다운로드된 파일 확인하기¶

    목표: 실제로 어떤 데이터가 들어있는지 확인하기

    따라하기: 1. 다운로드 폴더에서 .csv 파일을 찾으세요 2. 마우스 오른쪽 클릭 → "프로그램으로 열기" → "메모장" 을 선택하세요 - (또는 Excel을 선택해도 좋아요!) 3. 파일이 열리면, 위에서 처음 5줄 정도를 읽어보세요

    예를 들어 "미세먼지" 데이터라면 이렇게 보일 거예요: 

    지역,날짜,미세먼지,초미세먼지
서울,2024-01-15,45,28
부산,2024-01-15,52,31
대전,2024-01-15,38,22

    💡 이게 CSV 파일의 모습이에요! 첫 번째 줄이 "헤더(열의 제목)"이고, 그 아래가 실제 데이터입니다.

    Step 6️⃣: 파일을 분석 프로그램에 열기 (선택사항)¶

    목표: 파이썬이나 엑셀에서 데이터 분석 시작하기

    파이썬을 배운 분이라면 이렇게 해보세요:

    import pandas as pd

# CSV 파일 불러오기
# 'airquality.csv' 부분을 다운로드한 파일 이름으로 바꾸세요
data = pd.read_csv('airquality.csv')

# 처음 5줄 확인
print(data.head())

# 기본 통계 보기
print(data.describe())

    파이썬이 아직 낯설다면 그냥 엑셀에서 열어서 봐도 돼요! 1. CSV 파일을 마우스 오른쪽 클릭 2. "프로그램으로 열기" → "Excel" 3. 데이터를 표 형태로 볼 수 있어요!

    ✅ 축하해요! 이제 당신도 공공데이터를 다운로드하고 볼 수 있는 사람이에요!

    ⚠️ 자주 하는 실수¶

    실수 1️⃣: "파일을 다운로드했는데 열 수가 없어요"¶

    왜 이런 일이 생기나요? - 특수한 파일 형식이라서 메모장으로 열 수 없는 경우가 있어요 - 파일이 손상됐을 수도 있어요

    이렇게 해결해요: - Excel이나 Google Sheets에서 열어보세요 (훨씬 깔끔해요!) - 또는 파이썬의 pandas로 읽으면 자동으로 정리돼요

    실수 2️⃣: "원하는 데이터가 없어요"¶

    왜 이런 일이 생기나요? - 검색 단어가 너무 구체적일 수 있어요 - 포털에 정말 없는 데이터를 찾고 있을 수도 있어요

    이렇게 해결해요: - 검색 단어를 짧고 일반적으로 바꿔보세요 ("대전 맛집" 대신 "음식점") - "인기 데이터" 섹션을 보면서 대안을 찾아보세요 - 여러 포털을 확인해보세요 (Kaggle, Google Dataset Search 등)

    실수 3️⃣: "데이터가 너무 커서 컴퓨터가 느려져요"¶

    왜 이런 일이 생기나요? - 너무 큰 파일을 한 번에 불러들이면 메모리 부족이 돼요 - 특히 오래된 컴퓨터에선 더 그래요

    이렇게 해결해요: - 파이썬에서 chunksize 옵션으로 조금씩 읽으세요: 

    for chunk in pd.read_csv('bigfile.csv', chunksize=10000):
    # 조금씩 처리
    print(chunk.describe())
    - 또는 데이터 일부만 다운로드해서 시작해보세요

    📌 이 장의 핵심 정리¶

    ✅ 배운 것들을 한눈에 정리해요:

    데이터 수집의 4가지 방법 - 설문조사: 누군가에게 직접 물어보기 (정확하지만 느려요) - 관찰/센서: 자동으로 측정하기 (대량 수집 가능, 프라이버시 주의) - 웹 크롤링: 인터넷 데이터 자동 수집 (빠르지만 법적 문제 확인 필요) - 공공데이터: 정부 공개 데이터 (신뢰도 높고 무료, 형태 제한 있음)

    1차 vs 2차 데이터 - 1차: 내가 직접 수집한 데이터 (정확하지만 오래 걸림) - 2차: 남이 만든 데이터를 다시 사용 (빠르지만 수정 불가)

    공공데이터포털 활용 - 무료로 한국의 각종 공식 데이터를 다운로드할 수 있어요 - CSV 형식으로 다운받으면 Excel이나 파이썬에서 바로 쓸 수 있어요

    데이터 수집의 윤리 - 개인정보 보호 ✅ - 저작권 존중 ✅ - 이용약관 확인 ✅ - 투명한 목적 공개 ✅
