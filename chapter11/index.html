    Chapter 11. 숫자가 들려주는 이야기 — 기초 통계량 이해하기¶

    🎯 이 장의 학습 목표¶

    • 평균, 중앙값, 최빈값의 차이를 정확하게 설명할 수 있습니다
    • pandas의 describe() 메서드로 기초 통계량을 직접 산출할 수 있습니다
    • 표준편차가 무엇이며 왜 중요한지 이해합니다
    • 기초 통계량만으로 데이터의 전체 경향을 해석할 수 있습니다

    예상 학습 시간: 약 2시간 (이론 50분 + 실습 60분 + 정리 30분)

    📚 미리 알아야 할 것¶

    이전 장에서 배운 내용: - Series와 DataFrame: pandas의 기본 자료구조 - 데이터 불러오기: CSV 파일을 pandas로 읽는 방법 - 기본 탐색: head(), info() 메서드로 데이터 살펴보기

    이 장에서는 데이터 안에 숨어있는 의미를 숫자로 드러내는 방법을 배워요!

    💡 왜 이걸 배우나요?¶

    데이터를 마주쳤을 때, 가장 먼저 해야 할 질문은 이것입니다:

    "이 데이터의 전체적인 모습은 어떻게 생겼을까?"

    예를 들어볼게요. A반과 B반의 수학 시험 성적을 비교한다고 해봅시다.

    • A반: 평균 75점
    • B반: 평균 75점

    같은 평균이라고 해서 두 반의 학력이 같을까요? 아닙니다!

    A반의 성적: 73, 74, 75, 76, 77 (거의 다 비슷함)
    B반의 성적: 40, 60, 75, 90, 100 (매우 다름!)

    평균만으로는 데이터의 진짜 모습을 알 수 없어요. 그래서 평균, 중앙값, 표준편차 같은 여러 통계량을 함께 봐야 합니다. 이들이 데이터가 들려주는 이야기를 완성시켜주거든요.

    📚 핵심 개념¶

    개념 1: 평균, 중앙값, 최빈값 — 데이터의 중심을 보는 3가지 방법¶

    🎪 비유로 이해하기¶

    한 반의 학생들이 원탁에 둘러앉아 있다고 생각해보세요.

    • 평균(Mean): 모든 학생의 키를 더해서 명수로 나눈 값. "대표적인 키"를 찾으려는 시도예요.
    • 중앙값(Median): 키 순서대로 줄을 세웠을 때 정확히 가운데 서 있는 학생. 극단적인 값의 영향을 덜 받아요.
    • 최빈값(Mode): 가장 많이 나타나는 키. 예를 들어 교실에 167cm인 학생이 5명이면 최빈값은 167cm예요.

    📖 정확한 정의¶

    평균(Mean) 

    평균 = 모든 값의 합 ÷ 개수
    가장 흔하게 사용하지만, 극단적인 값에 쉽게 영향을 받습니다.

    중앙값(Median)
    데이터를 작은 순서대로 정렬했을 때 정확히 중간에 오는 값입니다. 개수가 짝수면 중간 두 값의 평균을 취합니다. 극단적인 값에 강한 자료예요.

    최빈값(Mode)
    가장 자주 나타나는 값입니다. 범주형 데이터(선호도, 색상 등)에 유용합니다.

    🎯 예시로 확인¶

    급식 만족도 설문 (5점 만점) 응답: 

    학생 1~10: 4, 5, 3, 5, 4, 5, 2, 5, 4, 5

    • 평균: (4+5+3+5+4+5+2+5+4+5) ÷ 10 = 4.2점
    • 중앙값: 순서대로 정렬하면 2, 3, 4, 4, 4, 5, 5, 5, 5, 5 → 중간 두 값(4, 5)의 평균 = 4.5점
    • 최빈값: 5점이 가장 많이 나타남 = 5점

    세 값이 모두 다르죠? 이게 바로 세 통계량이 각각 다른 정보를 전해준다는 증거입니다!

    graph LR A["데이터<br/>2, 3, 4, 4, 4, 5, 5, 5, 5, 5"] -->|모든 값을 더해 개수로 나눔| B["평균<br/>4.2점"] A -->|중간에 있는 값| C["중앙값<br/>4.5점"] A -->|가장 많은 값| D["최빈값<br/>5점"] B --> E["모든 데이터 고려<br/>극단값 영향 큼"] C --> F["순서만 고려<br/>극단값 영향 작음"] D --> G["빈도 중심<br/>범주형 데이터 유용"]

    개념 2: 표준편차 — 데이터가 얼마나 흩어져 있나요?¶

    🎪 비유로 이해하기¶

    두 학급의 체육 시간 100m 달리기 기록이 평균 13초예요.

    1학년 3반: 12.9, 13.0, 13.1, 13.2, 13.0 (모두 비슷해요)
    2학년 5반: 10.5, 12.0, 13.0, 14.5, 15.0 (제각각이에요)

    평균은 같지만 학생들의 실력이 퍼져있는 정도가 완전히 달라요. 이 "퍼진 정도"를 측정하는 게 표준편차(Standard Deviation)입니다.

    📖 정확한 정의¶

    표준편차는 "평균으로부터 얼마나 떨어져 있는가"를 나타내는 수치예요.

    • 표준편차가 작음 → 데이터가 평균 근처에 모여있음 (안정적, 예측 가능)
    • 표준편차가 큼 → 데이터가 넓게 퍼져있음 (불안정, 편차가 큼)

    💡 쉽게 기억하는 법: 표준편차는 "평균에서 얼마나 벗어났는가"의 평균이라고 생각하면 돼요!

    🎯 예시로 확인¶

    반 A의 5명 성적: 80, 82, 80, 79, 81 (표준편차 약 1.1)
    반 B의 5명 성적: 60, 70, 80, 90, 100 (표준편차 약 14.1)

    반 B의 표준편차가 훨씬 커요. 성적 편차가 크다는 뜻입니다.

    개념 3: describe() 메서드 — 한 번에 보는 모든 통계량¶

    pandas의 describe() 메서드는 데이터 한 줄로 기초 통계량을 모두 계산해줘요!

    출력되는 통계량들: - count: 비어있지 않은 값의 개수 - mean: 평균 - std: 표준편차 - min: 최솟값 - 25%: 1사분위수 (하위 25%) - 50%: 2사분위수 = 중앙값 - 75%: 3사분위수 (하위 75%) - max: 최댓값

    🔨 따라하기¶

    준비: 데이터 불러오기¶

    먼저 실습용 데이터를 만들어볼게요. 이전 장에서 저장했던 CSV 파일을 사용하거나, 아래처럼 직접 만들 수 있습니다.

    import pandas as pd
import numpy as np

# 샘플 데이터: 학교 급식 만족도 (100명 학생, 1~5점)
np.random.seed(42)
data = {
    '학생_번호': range(1, 101),
    '급식_만족도': np.random.choice([1, 2, 3, 4, 5], 100, p=[0.05, 0.1, 0.15, 0.35, 0.35]),
    '학교_만족도': np.random.choice([1, 2, 3, 4, 5], 100, p=[0.02, 0.08, 0.2, 0.4, 0.3])
}

df = pd.DataFrame(data)
print(df.head())

    예상 출력: 

       학생_번호  급식_만족도  학교_만족도
0       1      5      4
1       2      4      5
2       3      4      4
...

    ✅ 체크포인트: df.head()를 입력했을 때 처음 5개 행이 보이나요? 그럼 준비 완료입니다!

    Step 1: describe() 메서드 사용하기¶

    이제 describe() 메서드를 사용해 기초 통계량을 한 번에 봅시다.

    # 급식 만족도의 기초 통계량
print(df['급식_만족도'].describe())

    예상 출력: 

    count    100.00000
mean       4.17000
std        1.00000
min        1.00000
25%        4.00000
50%        4.00000
75%        5.00000
max        5.00000
Name: 급식_만족도, dtype: float64

    각 줄이 무엇을 의미하는지 읽어보세요: - count: 100명이 응답했어요 - mean: 평균 만족도는 4.17점 - std: 표준편차 1.0 (1점 정도 편차가 있어요) - 중간값(50%): 4점

    Step 2: 여러 열을 동시에 분석하기¶

    DataFrame 전체에 describe()를 적용하면 모든 수치형 열을 한 번에 봅니다.

    # 전체 DataFrame의 기초 통계량
print(df.describe())

    예상 출력: 

           급식_만족도    학교_만족도
count   100.00      100.00
mean      4.17        4.02
std       1.00        1.05
min       1.00        1.00
25%       4.00        3.00
50%       4.00        4.00
75%       5.00        5.00
max       5.00        5.00

    💡 해석 팁: 급식 만족도(평균 4.17)가 학교 만족도(평균 4.02)보다 조금 높네요. 급식이 더 만족스럽다는 뜻입니다!

    Step 3: 특정 통계량만 따로 계산하기¶

    때로는 원하는 통계량만 골라서 봐야 할 때가 있어요.

    # 평균
print("급식 만족도 평균:", df['급식_만족도'].mean())

# 중앙값
print("급식 만족도 중앙값:", df['급식_만족도'].median())

# 최빈값
print("급식 만족도 최빈값:", df['급식_만족도'].mode().values[0])

# 표준편차
print("급식 만족도 표준편차:", df['급식_만족도'].std())

# 최솟값과 최댓값
print("최솟값:", df['급식_만족도'].min(), "최댓값:", df['급식_만족도'].max())

    예상 출력: 

    급식 만족도 평균: 4.17
급식 만족도 중앙값: 4.0
급식 만족도 최빈값: 5
급식 만족도 표준편차: 1.0008...
최솟값: 1 최댓값: 5

    ✅ 체크포인트: 모든 코드가 에러 없이 실행되었나요? 그럼 Step 3까지 성공입니다!

    Step 4: 조건에 따라 통계량 비교하기¶

    "남학생과 여학생의 급식 만족도가 다를까?" 같은 질문을 하려면, 조건에 따라 데이터를 나눠서 분석해야 해요.

    먼저 성별 정보를 추가해봅시다.

    # 학생별 성별 정보 추가
df['성별'] = np.random.choice(['남', '여'], 100)

# 남학생의 급식 만족도 통계
print("=== 남학생 ===")
print(df[df['성별'] == '남']['급식_만족도'].describe())

print("\n=== 여학생 ===")
print(df[df['성별'] == '여']['급식_만족도'].describe())

    ⚠️ 자주 하는 실수¶

    실수 1: 평균만 믿고 결론 내리기¶

    ❌ 잘못된 생각 

    A팀 평균 성적: 75점
B팀 평균 성적: 75점
→ 두 팀은 실력이 같다!

    왜 문제인가요?
    A팀은 73~77점 (비슷한 수준)
    B팀은 40~100점 (극단적으로 다름)

    평균이 같아도 데이터의 퍼짐이 다르면 전혀 다른 의미입니다!

    ✅ 올바른 접근 

    print(f"A팀 표준편차: {team_a_scores.std():.2f}")
print(f"B팀 표준편차: {team_b_scores.std():.2f}")
# 표준편차까지 함께 봐야 진짜 의미를 알 수 있어요!

    실수 2: describe()가 모든 열에 적용되지 않음¶

    ❌ 잘못된 생각 

    df.describe()  # 문자형(범주형) 열이 빠졌어요!

    왜 문제인가요?
    describe()는 기본적으로 수치형 데이터만 분석합니다. 문자나 범주 데이터는 건너뜁니다.

    ✅ 올바른 해결법 

    # 수치형 데이터만 보기 (기본값)
df.describe()

# 모든 데이터 타입의 통계 보기
df.describe(include='all')

# 특정 열만 보기
df[['급식_만족도', '학교_만족도']].describe()

    실수 3: 중앙값과 평균을 헷갈리기¶

    ❌ 잘못된 생각 

    평균과 중앙값이 비슷하면 데이터가 균형잡혀 있다?

    왜 주의해야 하나요?
    극단적인 값이 있으면 평균과 중앙값이 크게 달라집니다.

    예: 급여 데이터 [200, 250, 300, 350, 10,000] - 평균: 2,220만원 (CEO 때문에 높음) - 중앙값: 300만원 (실제 직원들의 대표값)

    ✅ 올바른 해석 

    # 두 값의 차이 비교
mean_val = df['급여'].mean()
median_val = df['급여'].median()
diff = abs(mean_val - median_val)

if diff > 평균의 10%:
    print("극단값이 있을 수 있습니다!")
    print(f"중앙값 {median_val}이 더 신뢰할 만해요.")

    ✅ 스스로 점검하기¶

    • 평균, 중앙값, 최빈값의 차이를 자신의 말로 설명할 수 있나요?

    • 표준편차가 크다는 것이 무엇을 의미하는지 설명할 수 있나요?
    • 직접 만든 데이터로 describe()를 실행하고 결과를 해석해볼 수 있나요?
    • 조건문을 사용해 특정 그룹의 통계량을 따로 계산해본 적이 있나요?

    🚀 더 해보기¶

    응용 1: 이상치(Outlier) 찾아보기¶

    데이터에서 극단적인 값(이상치)을 찾는 한 가지 방법:

    # 사분위수(quartile)를 이용한 이상치 탐지
Q1 = df['급식_만족도'].quantile(0.25)  # 1사분위수
Q3 = df['급식_만족도'].quantile(0.75)  # 3사분위수
IQR = Q3 - Q1  # 사분위수 범위

# 이상치 범위
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df['급식_만족도'] < lower) | (df['급식_만족도'] > upper)]
print(f"이상치 개수: {len(outliers)}")

    응용 2: 여러 그룹의 통계량 한눈에 비교¶

    # 성별/학년별로 요약 통계 보기
summary = df.groupby('성별')['급식_만족도'].describe()
print(summary)

    📌 이 장의 핵심 정리¶

    ✅ 평균, 중앙값, 최빈값은 각각 다른 정보를 줍니다 - 평균: 모든 데이터를 반영하되 극단값에 민감 - 중앙값: 극단값에 강함 (소수가 부자인 사회에서도 중앙값이 더 실제적) - 최빈값: 범주형 데이터나 "가장 흔한"을 알 때 유용

    ✅ 표준편차는 데이터의 흩어짐을 측정합니다 - 표준편차 작음 = 데이터가 평균 근처에 모여있음 (안정적) - 표준편차 큼 = 데이터가 넓게 퍼져있음 (불안정)

    ✅ describe()로 한 줄에 8가지 통계량을 얻습니다 

    count(개수), mean(평균), std(표준편차), min, 25%, 50%, 75%, max

    ✅ 기초 통계량으로 데이터의 전체 그림을 파악합니다 - 평균을 먼저 본 후 표준편차를 확인 - 극단값이 의심되면 중앙값 확인 - 여러 그룹을 비교할 땐 한 가지 통계량만 말고 여러 각도에서 봄

    🤔 마지막 점검 퀴즈¶

    상황: 두 반의 영어 시험 성적

    반 A: 평균 70점, 표준편차 2점
    반 B: 평균 70점, 표준편차 15점

    1. 어느 반이 성적이 더 일정한가요?
    → 반 A (표준편차가 작으니까 모두 비슷한 점수)

    2. 어느 반이 상위권 학생과 하위권 학생의 격차가 더 클까요?
    → 반 B (표준편차가 크면 퍼져있다는 뜻)

    3. 두 반의 "대표 성적"으로 70점이 적절할까요?
    → 반 A는 적절 / 반 B는 적절하지 않음 (편차가 크니까)
